# MMD 播放指南

支持 VMD 动作、口型、表情、眼神和镜头，可搭配音乐播放。支持单人及最多四名小队成员，无需 Blender。

Blender 编辑后的骨架动作和镜头可在 **Blender 联动** 分别加载，共用此播放器的进度、动作校准、物理、音乐与表情设置。操作见 [Blender 编辑指南](../tools/blender/endfield_poser_bridge/README.md)。

播放时自动以归零表情为基准；动作没有指定的表情保持为零，不叠加待机或手动表情。暂停保持当前动作表情，停止后恢复播放前的设置。备用 T 姿预览也使用归零表情。

VMD 自带的模型显示开关会自动生效：到指定帧隐藏或重新显示角色。暂停保持当前显示状态，拖动、重置和循环按对应帧更新；停止后恢复原状态。多人按各自的动作文件分别控制。此功能不包含材质透明、渐隐或局部隐藏表情。

> 不得制作或传播违反鹰角官方创作限制的产物。使用后果由用户自行承担，作者等在法律允许的范围内免责。动作、镜头和音乐须遵守各自授权，详见[用户协议](user-agreement.md)。

## 导入与校准

1. 进入角色场景，按 **L** 打开面板，勾选 **MMD 播放器**。
2. 点击 **打开 VMD**，选择动作文件。
3. 点击 **播放**，自动读取角色骨架并适配动作比例。

通常无需手动摆 T 姿。自动适配失败时会尝试已有校准；仍不可用时，展开 **高级 → 角色校准 → 备用手动 T 姿**，调整为身体直立、双臂平伸后确认保存。取消会恢复原姿态。只有口型或表情的文件无需身体校准。

升级后，若陈千语等角色此前提示自动适配失败，可点击 **重新自动适配** 再试；无需删除保存的手动校准。

有与动作配套的 PMX 时，可在 **高级 → 源骨架与参考姿态** 中选择；它不会替换游戏角色的外观。没有 PMX 时使用内置骨架。文件导入失败会保留此前成功加载的内容。

动作中的手臂扭转会自动分配给角色已有的上臂、前臂捩骨，改善拧臂和转腕时的变形；无需另调骨长，单人与多人播放均适用。

**高级 → 角色校准 → 按角色 PMX 校准拇指（含归零）**默认开启，自动使用对应角色的拇指手型，再叠加动作；其他手指保留游戏原生基准。单人、多人共用，可随适配预设保存。关闭后使用原生拇指基准，无需重新校准。

默认源骨架下，拇指归零手型与动作方向都使用该角色的 PMX 参考。手动选择源 PMX、T 姿或修改骨骼映射时，以手动选择的动作参考为准。`Finger0`、`Finger01`、`Finger02` 分别对应拇指根部、中节和末节；需要微调时，可在动作校准面板逐节调整比例或角度偏移。

内置 37 个角色的 PMX 参考，已编入 DLL，无需安装模型文件。缺少参考或骨架不兼容时回退到原生基准；末节参考不足时保留该节原生相对姿态，面板会显示实际校准节数。庄方宜的 PMX 指尖与末节重合，因此只校准前两节。校准不改变游戏骨长，也不覆盖保存的身体校准。

**重置动作**会回到 VMD 首帧；首帧若有握拳或拇指旋转，会保留动作中的手势。

首次运行新版会将旧身体／手指校准移到 `plugin/mmd/calibration-backups/before-native-finger-zero/`，播放时重新自动校准。表情校准、姿态和适配设置保留，新生成的身体校准也会保留。若自动校准失败，可重新进行备用 T 姿校准。

大体积 VMD 会在后台读取，请等待“导入完成”后再播放。超过文件或内存限制时会提示原因。

校准按角色保存，换人后会读取对应校准。若显示等待骨架，先等待角色加载，再尝试 **刷新骨骼**；必要时重新校准。

## 播放与位置

| 控件 | 用法 |
|---|---|
| 播放 / 暂停 | 开始或继续动作；暂停保持当前姿态 |
| 停止并恢复 | 恢复播放前的位置、姿态和相关设置 |
| 重置动作 | 回到首帧并暂停 |
| 进度条、前后逐帧 | 定位需要查看或保存的姿态 |
| 播放速度、循环 | 支持 0.25–2 倍速；默认 1 倍速、不循环 |
| 原地播放 | 限制水平移动，保留跳跃与上下起伏 |
| 位移比例、高度修正 | 在 **动作** 页调整；关闭自动适配后显示手动比例，高度可另调 |

自然播放结束后保持末帧，循环不会持续累积位置偏移。隐藏面板后继续播放；快捷键见[快速教程](tutorial.md#默认快捷键)。暂停后可以在姿态库保存当前身体姿态。

切人后可直接点播放：角色骨架尚未就绪时会短暂等待，衣物准备完成后继续；等待期间再次换人或停止会取消原请求。

播放及校准期间会隐藏已识别的手持道具，停止后恢复。**冻结头发／衣物**默认关闭；需要保持静止时再开启。切换角色或刷新骨骼会结束当前播放。

## 多人播放

在主面板勾选 **MMD 多人播放器**，打开独立窗口：

1. 准备好小队，等待各队员显示自动适配就绪。无需逐个切换和摆 T 姿；仅自动适配失败的角色需要备用手动校准。
2. 按界面显示的 **第 1–4 位**分别选择 VMD；不参与的位置取消勾选。每位队员下方显示校准状态。
3. 共用一个动作时，点击 **此动作应用到四人**，或 **单人面板当前动作 → 四人**。
4. 在 **队员站位与动作比例** 调整每人的位置和朝向。动作不含编舞站位时，可点 **四人横排**。
5. 点 **播放全队**，统一冻结并适配参与成员。无法适配时会提示具体队员并恢复原状态。播放、暂停、拖动、速度与循环共用一条时间轴。短动作到末帧后保持，循环按最长动作重新开始。

**共同原点是开始播放时当前操控角色的位置和朝向**，即使该角色未勾选参与，也以它为准。暂停、拖动和循环不改变原点。各人的站位偏移相对此原点；全为零时可能重叠。**原地播放**锁定动作水平移动，保留跳跃和高度修正。

勾选 **快捷键控制多人播放器** 后，可隐藏界面操作，实际按键会显示在窗口中。**停止并恢复全队**恢复各人播放前的姿态与设置；换人、换队或角色实例失效也会停止全队。

更换整套编队后可直接点播放，播放器会等待新队员模型和衣物恢复完成，再按新编队顺序开始；等待期间再次换队或停止会取消本次请求。

快捷键优先控制正在播放或暂停的播放器。打开单人动作、点击单人播放按钮会切回单人控制，面板会显示当前控制对象。T 姿预览期间请先确认保存或取消校准；按 **P** 可取消预览并解冻。

音乐和镜头文件与单人面板共用，由全队进度同步；镜头可固定在共同原点或跟随指定队员。骨架、比例和表情映射按角色独立处理，更换骨架后重新自动适配。

**站位与适配 → 全队衣物物理增强**默认开启，与单人开关独立；各队员分别适配，面板显示各自状态。暂停保留增强，停止后恢复原设置。关闭时保留游戏原有衣物物理。增强不包含队员之间的碰撞，多人播放也不接管队友寻路，建议在静止、非战斗场景使用。

多人功能仍在预发布验证中。游戏场景未提供其他队员实例时，对应位置会显示不可用；不会自动生成队员。

## 地形跟随

在播放器 **动作** 页勾选 **地形跟随（坡面 / 台阶）**。多人在 **站位与适配** 页开启 **全队地形跟随**，分别检测每位队员的脚下地面。

- **贴地强度**：0 保留原动作，1 完整应用地面修正；跳跃和抬脚保留。
- 暂停可检查脚底；拖动和循环会重新判断接地，停止后恢复播放前的位置。
- 镜头默认跟随地形高度补偿；需要固定构图时关闭镜头中的 **跟随角色高度修正**。多人以所选镜头队员的补偿为准。

地面接口不可用或没有检测到地面时会显示原因。该功能默认关闭，处理角色与地面的关系，不能消除衣服穿身体或角色之间的穿模。

## 动作幅度与 IK

在 **动作 → 动作校准…** 打开独立面板，展开 **动作幅度（全身 / 分部位）**，可分别调整躯干、头颈、手臂、手指和腿脚。开启该区的 **左右联动** 后，两侧数值一起变化。

整体与各部位均可设为 0–200%，最终幅度为两者相乘。例如整体 80%、腿部 50%，腿部最终为 40%。默认 100%；0% 回到该部位的基准姿势。幅度不改变播放速度、表情或整体移动距离，也不能保证消除穿模。

**动作 IK** 可在播放或暂停时手动切换：

| 模式 | 用途 |
|---|---|
| 跟随动作 | 默认选择，使用文件中的 IK 设置 |
| 强制开启 | 使用脚部等已支持的 IK 控制，观察脚底和弯膝效果 |
| 强制关闭 | 按动作原有骨骼旋转播放，可对照检查绷腿、崴脚等问题 |

腿部僵硬时先对照三种模式，再微调腿脚幅度。手臂方向明显不对时，停止播放，在 **高级 → 源骨架与参考姿态** 检查 A 姿 / T 姿选择，或使用配套 PMX。插件不会按文件名或说明文件自动选择这些设置。

### 手动动作校准

单人从 **动作 → 动作校准…** 打开；多人从 **站位与适配 → 动作校准…** 打开。无需提供动作原始模型的 PMX。

面板顶部的 **校准对象** 可选择 **共用参数** 或 **第 1–4 位**。共用参数影响单人和未独立设置的队员；选择某位并开启 **此队员使用独立动作校准** 后，四肢伸展、手脚偏移、逐关节比例、移动比例和全身／部位幅度只影响该队员。首次开启会复制共用参数；关闭后恢复共用，但保留独立值。多人站位列表也有 **单独校准动作…** 入口。

1. 在面板顶部拖动进度条，选中需要修正的一帧并暂停；双击可输入秒数，也可用 `<`、`>` 逐帧检查。多人使用全队共同时间轴，切换校准对象不改变播放进度。
2. 在 **四肢伸展与手脚落点** 选择一侧手臂或腿。上臂、前臂、大腿和小腿的伸展比例可分别设为 50–150%；略微降低可将手脚收近。偏移按该侧整条臂／腿长计算，正值向左、上、前；左右联动时自动镜像横向偏移。
3. 在 **逐关节比例与偏移** 调整肩、肘、腕、髋、膝、踝、躯干或每节手指。**动作比例** 范围 0–200%，与全身、部位幅度相乘；100% 保留动作，0% 保持关节基准角度。勾选 **XYZ 偏移** 后，同一行的三个滑条可叠加局部轴旋转角度（−180° 至 180°），不受动作比例缩放。双击可输入度数；**偏移归零** 只清除角度，**复位** 同时恢复该关节比例。下方 **联动方向** 可为每对关节的 X、Y、Z 分别选 **同向**（例如 +10° → +10°）或 **镜像**（+10° → −10°），开启左右联动后生效；左右两侧共用规则，从任一侧调整均可。各队员可分别设置，规则和角度随预设保存；旧预设默认全部同向。
4. **整体移动比例** 分别控制横向、上下起伏和前后位移。原地播放、高度修正和地形跟随仍然生效。
5. 暂停或播放时均可预览。取消 **启用动作校准** 可对照原动作，重新开启会保留数值；**全部复位** 将比例恢复到 100%、偏移归零。

**保存动作校准 / 载入动作校准** 仅操作当前选中的校准对象，首次打开默认目录 `plugin/mmd/motion-presets/`，之后记住上次选中文件的文件夹，重启后仍有效；文件夹不存在时回到默认目录。动作校准与骨架适配分别记忆，保存和读取共用同一目录记录。为队员载入预设会自动开启独立校准；旧版动作校准预设也可使用。每位队员可以分别保存、载入。

设置在本次运行中保持，停止播放或一键共用动作不会清除。多人设置按小队位置管理，换队或调整顺序后请检查；重新启动插件后需载入预设。它与角色的自动骨架校准分开，不会覆盖身体校准文件。

伸展比例改变动作中的手脚目标，保留角色真实骨长；目标过远时会限位。关节幅度和地形跟随还可能改变最终落点，因此建议先调伸展，再调关节，并检查整个动作。这是手动适配工具，不会自动识别双手接触、保证脚底锁定或消除穿模；不修改原 VMD，也不处理 PMX 刚体关节。

## 口型、表情与眼神

在独立的 **表情 → 眼睛朝向** 勾选 **MMD 播放时锁定摄像机**。单人和四人共用此入口，支持暂停及隐藏面板，兼容游戏镜头和 MMD 镜头。

**锁定强度** 为 0 时保留动作眼神，为 1 时看向镜头；中间值混合两者。关闭锁定后恢复当前动作的眼神，眉毛、眨眼和口型不受影响。镜头过近时限制双眼汇聚，转到侧后方时视线逐渐回正。

镜头短暂不可用时保持上次眼神方向，恢复后继续跟踪。

**镜头跟踪（当前角色）** 中可调转动幅度、注视深度和平滑时间，必要时微调眼球中心的计算偏移。按角色保存，多人分别使用各自设置；操作说明见[眼睛朝向](tutorial.md#眼睛朝向)。

**校正与限位（当前角色）** 可在播放中微调镜头方向偏差和四向范围，按角色自动保存。优先使用匹配的 PMX 虹膜与眼眶参考，面板会标明当前基准；限位在混合和双眼汇聚后仍生效。

角色专属的 MMD 表情参考自[茶叶味香皂](https://space.bilibili.com/3546783156276148)的终末地 MMD 模型。内置校准随安装包自动安装，无需另行下载模型。没有动作文件时，也可使用[表情面板的 MMD 模式](tutorial.md#手动调节-mmd-表情)手动控制。

**追加口型 / 表情 / 眼神**只添加这些轨道，不替换身体动作。追加内容与动作共用进度；同名轨道由后追加文件完整替换，其余轨道保留。也可以直接打开纯表情 VMD。

在播放器 **表情 → 角色表情与强度** 中，为眉毛、眼部、嘴部、脸颊分别选择：

- **角色专属映射**（默认）：使用该角色 PMX 生成的独立校准，保留不同角色的眉形、眼形和嘴形。
- **固定表情映射**：使用原有游戏表情通道。
- **关闭**：该部位保持中性。

**专属校准缺失时使用固定映射** 默认开启。新角色没有校准、骨架不匹配或某条表情无法适配时，可以用此开关决定是否兜底。关闭后未匹配的轨道不产生表情。

每个部位和整体强度均可设为 0–200%，播放、暂停时都能调整。例如整体 150%、眼部 50%，眼部最终为 75%。0% 表示中性表情；强度不会改变眼神朝向。

要覆盖动作里的眼神，在 **表情 → 眼睛朝向** 选择 **手动方向** 或 **锁定当前摄像机**。切回 **跟随游戏 / 动作** 后恢复当前动作的眼神。详见[眼睛朝向](tutorial.md#眼睛朝向)。

**示例：嘴部沿用固定映射。** 其余部位保持角色专属，嘴部选择固定表情映射，再分别调整强度。

**复位全部强度** 恢复所有强度到 100%；**全部使用角色专属映射** 只更改来源。模式、强度及手动映射均会保存；手动的专属表情映射按角色分别保存。

在播放器 **表情 → 手动绑定（高级）** 中，可将一条 VMD 表情绑定到多个目标。标签沿用 MMD 表情面板的中文翻译，悬停可查看原名，也可用中文或原名搜索。

展开一条表情，点击 **添加表情** 组成组合，再分别调整每项强度；修改自动保存，旧的单项绑定仍可使用。角色专属绑定按角色保存，单人和多人播放共用；**编辑映射表**只决定编辑对象，实际使用方式由上方各部位设置决定。

组合闭眼表情会按左右眼分别限制闭合幅度，避免眨眼、笑眼等叠加后眼睑闭合过头；提高眼部强度时也会生效。

冻结角色或暂停单人播放后，按住下拉列表中的 **预览** 可查看单个标签，**按住预览组合** 可查看整组效果，松开即恢复原表情。预览以 100% 独立查看所选映射，不改变播放设置。多人播放期间请先停止，再逐个角色编辑。

### 添加角色校准

将生成的 `*.face.json` 放入游戏目录的 `plugin/mmd/character-faces/`，停止播放后点击 **重新读取校准**。切换角色时自动选择对应文件；界面会显示当前角色和可用表情数量。

若已有 PMX，可在源码目录生成校准：

```powershell
python -m pip install numpy scipy
python tools/compile_character_faces.py "你的PMX文件夹" --output "游戏目录/plugin/mmd/character-faces"
```

工具可递归处理整个文件夹，也可输入单个 PMX。无需 Blender；生成后游戏播放不依赖 Python 或原 PMX 路径。模型和校准数据由使用者自行准备，普通安装包不包含本机素材。

校准尽量保留源模型形状，但顶点表情与游戏控制能力有差异，不能保证每个表情完全一致。没有表情轨道或缺少可对应控制点的模型无法生成专属校准；近似及未映射项目见 **导入报告**。瞳孔缩放、牙齿显隐、腮红等特殊效果不在此次适配范围内。

## 音乐同步

在 **镜头与音乐 → 音乐同步 → 选择音乐** 中选择 WAV、MP3、M4A 等支持的音频。无需选择音乐也能播放动作。

- **随动作播放音乐**：开启后跟随播放、暂停、拖动、重置和循环。
- **音乐偏移（秒）**：正值让音乐晚开始，负值从音乐中途开始。例如 `2` 表示动作第 2 秒开始播放音乐；`-2` 表示动作开始时从音乐第 2 秒播放。多人面板滑条范围为 `-120～120` 秒，也可双击输入数值。
- **音乐音量**：只调整插件配乐，不影响游戏音量。

变速会同时改变音乐速度和音高。音乐先结束时动作继续，动作结束时音乐停止。停止后可更换或移除音乐；所选文件仅在本次运行中保留。

## 固定跟踪镜头

在单人或多人的 **镜头与音乐 → 固定跟踪镜头** 中勾选 **锁定当前角色**，无需导入镜头文件。镜头保持开启时的拍摄方向，只跟随角色位移和跳跃，人物转身不会带动镜头绕圈。

勾选 **不跟踪跳跃** 后，镜头锁定勾选时的高度，只跟随水平位移；坡道、台阶也不会改变镜头高度，仍可用上下偏移调整。默认关闭。

**跟随平滑（秒）** 默认 0.15，数值越大，位移跟随越柔和，但滞后也越明显；设为 0 关闭，支持双击输入和保存。可与“不跟踪跳跃”一起使用，拍摄方向和焦距保持固定。首次开启及大幅瞬移时直接对齐，避免镜头长距离追赶。

**固定距离** 控制镜头与取景点的距离，**固定焦距** 控制取景范围；用 **跟踪点偏移** 调整构图和身高差异，也可微调水平、俯仰角度。支持双击滑条输入，参数可保存，下次需手动开启。

开启时优先于 VMD 镜头；暂停、停止动作或关闭面板后仍继续跟踪。关闭跟踪后交还原镜头控制，切换角色时自动退出。焦点随取景点移动；非物理相机使用 35mm 等效焦距。

## MMD 镜头

在 **镜头与音乐 → MMD 镜头 → 选择镜头 VMD** 中选择配套镜头。含镜头的动作 VMD 也可直接读取；单独播放镜头无需身体校准。镜头随同一进度条播放、暂停、拖动和循环。

常用的原点、偏移、身高和距离调整直接显示；时间偏移、视角、单位比例和切镜放在 **高级构图与切镜** 中。

| 设置 | 用法 |
|---|---|
| 固定播放起点 | 默认模式，以开始播放时的人物位置和朝向为固定参考 |
| 跟随角色位移 | 让整套镜头额外跟随角色移动，可关闭上下起伏跟随；多人可指定队员 |
| 按角色身高适配构图 | 使用已校准骨架的头脚高度调整观察点和距离；没有校准时使用单位比例 |
| 偏移（左右／上下／前后） | 沿播放起点的角色方向调整构图，单位为米 |
| 构图整体倍率、镜头距离倍率、视角偏移 | 分别调整整套构图、远近和取景范围 |
| 整体朝向 | 调整整套镜头面向 |
| 跟随角色高度修正 | 将手动高度与地形补偿同步给镜头，可独立关闭 |
| 单位比例跟随动作 | 未使用身高适配时生效；关闭后可独立调整镜头单位比例 |
| 镜头时间偏移 | 正值延后，负值提前；不改变动作与音乐的时间 |
| 切镜方式 | 默认保留相邻关键帧硬切；逐帧镜头可选连续插值，也可暂停后手动标记当前段末尾切镜 |
| 复位镜头调整 | 恢复默认镜头参数 |

VMD 没有统一的“跟随人物”标志。先用默认模式；若人物走出画面，再尝试追踪。文件本身已有跟拍时，额外开启追踪可能导致偏移过大。

**调整构图**：先启用身高适配，再在暂停时微调上下偏移和距离，最后检查远近景。多人面板也可直接调整。停止或关闭镜头后恢复游戏视角。

拍照模式开启景深时，对焦距离随 MMD 镜头的目标点更新，暂停和拖动进度时也会同步。原来的光圈和虚化强度保持不变，停止后恢复原对焦距离。

点击 **保存此角色＋镜头设置**，下次选择相同角色与镜头时自动读取。设置保存在 `plugin/mmd/camera-settings.json`，按镜头内容区分，移动素材路径不会失效。没有点击保存的修改只在本次运行保留。

## 衣物物理

**衣物惯性物理增强**默认开启：衣物、头发、尾巴等部件会随横移、转身、起跳和落地摆动，并按实际挂点的运动计算响应，挂在外套或腰带上的饰物也会跟随其挂点。**衣物惯性强度**控制大块衣物、尾巴和耳部，**头发惯性强度**单独控制头发；展开 **饰物惯性** 可分别调整飘带、腰带／绳带和挂件。各项默认 1，支持双击输入、复位及随适配预设保存。头发范围 0–3，其他强度范围 0–2；头发或饰物设为 0 时，仅关闭该类额外受力。

跳跃反应较弱时可只提高头发强度；饰物甩动过大时，降低对应类别强度。实际幅度仍受原有约束和受力上限限制。单人和多人共用设置，各角色分别计算，无需额外校准。长飘带按整条长度计算受力，高阻尼袖口飘带会单独调整，停止时恢复。暂停后自然收敛，拖动、循环和切人清除旧运动记录，停止后交还游戏物理。

**饰物层间碰撞**默认开启，只为能确认内外关系且存在合适原有碰撞体的部件补充接触，面板显示已补充的组数。已有专用层间处理、关系不明确或缺少碰撞形状的部件保留原处理，因此不会覆盖所有穿模。可关闭此项作对照，停止时移除新增接触。

开启服装碰撞增强后，会检查各角色衣物的小腿碰撞，保留已有覆盖并补充缺失部分。男女管理员的外套进一步放开上身活动点，保留肩领锚点，并分别收窄腰部碰撞范围。停止或关闭增强后恢复原设置；特殊皮肤和大幅动作仍需实际检查效果。

面板显示已接入的衣物、头发、尾巴、耳部和挂件数量。该功能可与服装碰撞增强一起使用；没有原生物理模拟的部位不会自动变软，也不能保证消除穿模。保持 **冻结头发／衣物** 关闭才能看到摆动。

想让这些部位更容易飘起，可提高 **衣物轻盈度**：范围 0–100%，默认 0%，支持双击输入、复位及随适配预设保存。它增强转身、横移的上扬效果，也增加跳跃时上升滞后、下落上飘的反应。耳部和挂件响应较小；原有重力不变，停下后自然回落。

**第二骨骼物理增强**已内置，默认关闭，仅用于单人、多人 MMD 动作播放。开启后随身体上下、左右、前后运动及转身产生惯性摆动；可分别调整方向响应、回弹频率、阻尼和角度上限。点击 **保存第二骨骼物理设置** 后，下次启动自动读取。

单人、多人共用参数，各角色分别计算。暂停保持，拖动或循环重置惯性，停止恢复开始前姿态；第二骨骼增强可独立于服装碰撞增强使用，不支持的骨架保持原样。已安装普通 SBM 时请先退出游戏并停用 `plugin/sbm.dll`，避免双重控制；支持协作接口的版本可以共存。

在 **动作 → 衣物物理** 中，保持 **冻结头发／衣物** 关闭，播放和暂停时让衣物、头发与尾巴继续模拟。

在 **衣物物理** 勾选 **服装碰撞增强**，播放器会自动匹配当前服装。首次准备需要等待，面板会显示准备状态和已增强部位数；关闭增强或停止播放后恢复原有衣物。无法匹配的部位保留原有物理。

开启增强后会先准备衣物，再同步开始动作和音乐；多人模式会等待参与的队员全部就绪。准备期间仍可暂停、拖动进度或停止。若提示准备失败，可停止重试或关闭增强。

已增强的飘带反复抖动时，可在停止并恢复后调整 **飘带减振**，下次播放生效。默认 30%，0% 使用原始阻尼；数值越高，飘动越弱。此设置可随适配预设保存，不能代替碰撞适配。

默认使用 **游戏原始尺寸**。需要额外调节时展开 **高级：碰撞体尺寸**，切到 **腿根半径补偿**；裙摆被撑开时减小数值。这些选项可随适配预设保存。

男女管理员的原版外套会增加胸前、横向腰部碰撞体，并减少连续固定点，让腰部和衣摆参与摆动。原有蒙皮与其他碰撞体保持不变。
男管理员另有骨盆过渡碰撞体，与腰部、左右大腿重叠，补足腰腿交界处的覆盖。

效果取决于服装与动作，仍可能穿模。替换皮肤匹配失败或变形异常时关闭增强；脚底过低可用 **高度修正** 调整。

## 骨架适配与追加骨骼

特殊动作出现缺失或方向错误时，停止播放，在 **高级** 页展开 **骨架适配 / 追加骨骼**：

1. 选择合适的 A/T 原始姿态或配套 PMX。
2. **准标准骨补全**默认全部开启，包含 Groove、上半身2、肩、捩骨、脚 IK 父级和 D/EX 骨等。需要时可单独关闭；载入适配预设时使用预设里的选择。
3. 在 **动作轨道 → 源骨骼** 中指定动作对应的骨名。
4. 在 **源骨骼 → 角色部位** 中指定要控制的身体部位；不需要的项目可设为不控制。
5. 点击 **应用适配**，播放检查，再停止并 **保存适配预设**。

仍缺少骨骼时，可手动追加或插入，设置名称、父级和位置参考。新增后先应用，再将它选作后续映射目标。这里追加的是动作适配用的骨骼，不会为游戏衣服增加可变形的骨骼。

预设可保存骨架适配、IK、动作幅度、动作校准和衣物物理设置，之后通过 **载入适配预设** 复用。旧预设缺少动作校准时使用默认比例。PMX 预设需配合相符的参考文件；预设不会自动按动作名称加载。

播放时保留游戏已显示的满潜等常驻特效；待机道具仍会隐藏，停止后恢复。

## 排查与限制

| 表现 | 建议 |
|---|---|
| 表情没有变化 | 检查当前帧是否有表情、该部位选择的映射及 **导入报告** |
| 镜头离角色太远或太近 | 先复位，再调上下偏移和距离比例 |
| 音乐不同步 | 先检查播放速度，再调整音乐偏移 |
| 动作感觉卡顿 | 隐藏面板对照，查看播放器显示的更新频率；它不一定等于游戏帧率 |
| 改完设置仍无变化 | 检查是否点击 **应用适配**；编辑映射表后确认对应部位已选择该映射 |

不包含 MMD 灯光、模型外观导入或 MMD 物理。特殊动作和角色需要逐项检查效果。数据保存位置和问题反馈见 [README](../README.md)。
