# MMD 播放指南

支持 VMD 动作、口型、表情、眼神和镜头，可搭配音乐播放。一次控制当前角色，无需 Blender。本文以 0.4.42 源码功能为准，标注 0.4.42 的功能尚未包含在 0.4.41 安装包中。

> 不得制作或传播违反鹰角官方创作限制的产物。使用后果由用户自行承担，作者等在法律允许的范围内免责。动作、镜头和音乐须遵守各自授权，详见[用户协议](user-agreement.md)。

## 导入与校准

1. 进入角色场景，按 **L** 打开面板，勾选 **MMD 播放器**。
2. 点击 **打开 VMD**，选择动作文件。
3. 完成当前角色的校准，再点击 **播放**。

自动校准失败时，展开 **角色校准 → 手动 T 姿预览**，用骨骼面板把角色调整为身体直立、双臂平伸的 T 姿，再确认保存。取消会恢复原姿态。只有口型或表情的文件无需身体校准。

有与动作配套的 PMX 时，可选作骨架参考；它不会替换游戏角色的外观。没有 PMX 时使用内置骨架。文件导入失败会保留此前成功加载的内容。

校准按角色保存，换人后会读取对应校准。若显示等待骨架，先等待角色加载，再尝试 **刷新骨骼**；必要时重新校准。

## 播放与位置

| 控件 | 用法 |
|---|---|
| 播放 / 暂停 | 开始或继续动作；暂停保持当前姿态 |
| 停止并恢复 | 恢复播放前的位置、姿态和相关设置 |
| 重置动作 | 回到首帧并暂停 |
| 进度条、前后逐帧 | 定位需要查看或保存的姿态 |
| 播放速度、循环 | 支持 0.25–2 倍速；默认 1 倍速、不循环 |
| 原地播放 | 限制水平移动，保留跳跃与上下起伏 |
| 位移比例、高度修正 | 调整移动范围和角色整体高度 |

自然播放结束后保持末帧，循环不会持续累积位置偏移。隐藏面板后继续播放；快捷键见[快速教程](tutorial.md#默认快捷键)。暂停后可以在姿态库保存当前身体姿态。

播放及校准期间会隐藏已识别的手持道具，停止后恢复。**冻结头发／衣物**默认关闭；需要保持静止时再开启。切换角色或刷新骨骼会结束当前播放。

## 动作幅度与 IK

展开 **动作幅度（全身 / 分部位）**，可以统一调整全身，或单独调整躯干、头颈、手臂、手指和腿脚。开启 **左右联动** 后，两侧数值一起变化。

整体与各部位均可设为 0–200%，最终幅度为两者相乘。例如整体 80%、腿部 50%，腿部最终为 40%。默认 100%；0% 回到该部位的基准姿势。幅度不改变播放速度、表情或整体移动距离，也不能保证消除穿模。

**动作 IK** 可在播放或暂停时手动切换：

| 模式 | 用途 |
|---|---|
| 跟随动作 | 默认选择，使用文件中的 IK 设置 |
| 强制开启 | 使用脚部等已支持的 IK 控制，观察脚底和弯膝效果 |
| 强制关闭 | 按动作原有骨骼旋转播放，可对照检查绷腿、崴脚等问题 |

腿部僵硬时先对照三种模式，再微调腿脚幅度。手臂方向明显不对时，停止播放，检查 **动作原始姿态** 的 A 姿 / T 姿选择，或使用配套 PMX。插件不会按文件名或说明文件自动选择这些设置。

## 口型、表情与眼神

**追加口型 / 表情 / 眼神**只添加这些轨道，不替换身体动作。追加内容与动作共用进度；同名轨道由后追加文件完整替换，其余轨道保留。也可以直接打开纯表情 VMD。

在 **表情模板与强度** 中，为眉毛、眼部、嘴部、脸颊分别选择：

- **游戏表情映射**：使用角色自带的表情，所有部位默认选择此项。
- **通用模板映射**：提供更多眉形、眼睑、嘴角、噘嘴、抿嘴和鼓腮变化。不同角色的效果可能需要微调。

每个部位和整体强度均可设为 0–200%，播放、暂停时都能调整。例如整体 150%、眼部 50%，眼部最终为 75%。0% 表示中性表情；强度不会改变眼神朝向。闭眼等效果达到上限后不会继续放大。

**示例：嘴部用游戏映射，其他部位用模板。** 将眉毛、眼部和脸颊设为通用模板，嘴部保留游戏表情映射，再分别调整强度。

| 按钮 | 作用 |
|---|---|
| 复位全部强度 | 所有强度恢复 100%，保留映射选择 |
| 恢复默认分区 | 所有部位切回游戏映射，保留强度 |
| 还原 0.4.38 通用模板（0.4.42） | 所有部位切为模板，全部强度恢复 100% |

以上按钮不清除手动轨道映射。分区选择和强度会保存供下次使用。

未识别的表情可在停止后展开 **表情映射**，选择对应映射表，再绑定目标、调整单轨强度或忽略轨道。**编辑映射表**只决定正在编辑哪张表；实际使用哪一种，仍由上方各部位选择决定。

游戏映射不包含全部嘴角、噘嘴或鼓腮效果；需要时将对应部位改为模板。没有表情关键帧的片段不会因提高强度而产生表情。ω 嘴和三角嘴是近似效果，不支持瞳孔缩放、牙齿显隐、腮红、眼泪等特效。未匹配的项目见 **导入报告**。

## 音乐同步

展开 **音乐同步 → 选择音乐**，选择 WAV、MP3、M4A 等支持的音频。无需选择音乐也能播放动作。

- **随动作播放音乐**：开启后跟随播放、暂停、拖动、重置和循环。
- **音乐偏移（秒）**：正值让音乐晚开始，负值从音乐中途开始。例如 `2` 表示动作第 2 秒开始播放音乐；`-2` 表示动作开始时从音乐第 2 秒播放。
- **音乐音量**：只调整插件配乐，不影响游戏音量。

变速会同时改变音乐速度和音高。音乐先结束时动作继续，动作结束时音乐停止。停止后可更换或移除音乐；所选文件仅在本次运行中保留。

## MMD 镜头

展开 **MMD 镜头 → 选择镜头 VMD**，选择与动作配套的镜头。含镜头的动作 VMD 也可直接读取；单独播放镜头无需身体校准。镜头随同一进度条播放、暂停、拖动和循环。

| 设置 | 用法 |
|---|---|
| 按文件轨迹／固定播放起点 | 默认模式，以开始播放时的人物位置和朝向为固定参考 |
| 追踪当前角色位移 | 让整套镜头额外跟随角色移动，可关闭上下起伏跟随 |
| 镜头偏移（左右／上下／前后） | 调整构图；上下偏移可适配角色身高 |
| 距离比例、视角偏移 | 调整远近和取景范围 |
| 整体朝向 | 调整整套镜头面向 |
| 镜头比例跟随动作位移比例 | 默认开启；关闭后可独立调整镜头单位比例 |
| 相邻帧视为切镜 | 默认开启，保持快速镜头切换；需要平滑过渡时再关闭 |
| 复位镜头调整 | 恢复默认镜头参数 |

VMD 没有统一的“跟随人物”标志。先用默认模式；若人物走出画面，再尝试追踪。文件本身已有跟拍时，额外开启追踪可能导致偏移过大。

**适配身高**：暂停在正面镜头，先调整上下偏移，使人物居中，再调距离比例，最后播放检查远近景。暂停时可以调整，停止或关闭镜头后恢复游戏视角。镜头参数仅在本次运行中保留。

## 地面与裙摆碰撞辅助

展开 **地面与裙摆碰撞辅助**。先暂停到有问题的姿态，再逐项调整并播放检查。

- **脚底防穿地**默认关闭。开启后可选 **探测游戏地面**，或使用 **固定平面（起始脚底）**。
- 脚底过低时调整 **鞋底厚度补偿** 或 **地面高度微调**；整个人下沉时用播放器的 **高度修正**。
- **脚部跟随坡面**用于斜坡；**接触修正强度**和 **最大抬脚修正**控制调整程度。
- 检查裙摆时保持 **冻结头发／衣物**关闭，再尝试 **BBC 原生同帧碰撞**、**裙摆碰撞增强**、**补齐腿部原生碰撞**。
- **腿部碰撞余量**从较小值开始增加。裙子被撑得过大时减小余量，或关闭 **手动调整碰撞体尺寸**。
- 尾巴或衣物不动时，检查冻结选项，并尝试 **当前角色使用完整物理权重（含尾巴）**。**裙摆边碰撞**可作开关对照。

开启脚底防穿地后，即使动作 IK 关闭，仍会进行地面修正。碰撞辅助可能增加性能开销，也不能消除所有穿模；缺少衣物骨骼的长裙尤其受限，不提供手臂避让或衣物与地面的碰撞。

## 骨架适配与追加骨骼

特殊动作出现缺失或方向错误时，停止播放，展开 **骨架适配 / 追加骨骼**：

1. 选择合适的 A/T 原始姿态或配套 PMX。
2. 按需勾选 **準標準骨补全**，例如 Groove、上半身2、肩、捩骨、脚 IK 父级或 D/EX 骨。
3. 在 **动作轨道 → 源骨骼** 中指定动作对应的骨名。
4. 在 **源骨骼 → 角色部位** 中指定要控制的身体部位；不需要的项目可设为不控制。
5. 点击 **应用适配**，播放检查，再停止并 **保存适配预设**。

仍缺少骨骼时，可手动追加或插入，设置名称、父级和位置参考。新增后先应用，再将它选作后续映射目标。这里追加的是动作适配用的骨骼，不会为游戏衣服增加可变形的骨骼。

预设可保存骨架适配、IK、动作幅度和碰撞设置，之后通过 **载入适配预设** 复用。PMX 预设需配合相符的参考文件；预设不会自动按动作名称加载。

## 排查与限制

| 表现 | 建议 |
|---|---|
| 表情没有变化 | 检查当前帧是否有表情、该部位选择的映射及 **导入报告** |
| 镜头离角色太远或太近 | 先复位，再调上下偏移和距离比例 |
| 音乐不同步 | 先检查播放速度，再调整音乐偏移 |
| 动作感觉卡顿 | 隐藏面板对照，查看播放器显示的更新频率；它不一定等于游戏帧率 |
| 改完设置仍无变化 | 检查是否点击 **应用适配**；编辑映射表后确认对应部位已选择该映射 |

不包含多角色同步、MMD 灯光、模型外观导入或 MMD 物理。特殊动作和角色需要逐项检查效果。数据保存位置和问题反馈见 [README](../README.md)。
