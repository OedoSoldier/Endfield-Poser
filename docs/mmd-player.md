# MMD 动作播放器（0.4.17 开发版）

在游戏中按 **L** 打开面板，勾选 **MMD 播放器**。进入可操作角色的场景后，选择 **打开 VMD**，再按 **播放**。无需 Blender。播放器一次控制当前角色。

## 导入和校准

- VMD 支持 CP932 日文名称、中文文件路径、身体、手指、眼神和表情轨道。文件读取在工作线程完成；导入失败保留上一份动作。
- 默认使用标准 MMD 骨架，位移比例为 `0.08`。可以选择与动作对应的 PMX 2.0/2.1 作骨架参考，读取层级、静止位置、附加变换、固定轴和 IK。不会导入模型、材质或物理。PMX 模式默认按两套骨架的腿长计算位移比例，仍可手调。
- 首次播放从游戏 `SkinnedMeshRenderer.bones` 和 `Mesh.bindposes` 自动校准。校准使用实际父级和变换缩放，不使用旧摆姿功能的临时 A-pose。
- 自动校准失败时，展开 **角色校准 → 手动 T 姿预览**，用骨骼面板修正角色，使身体直立、双臂平伸、左右方向正确；确认保存后恢复原姿态。取消则直接恢复。必要骨骼缺失或校准失败时，身体动作不能播放。纯口型/表情文件无需身体校准。
- 0.4.1 修复手动预览侧倒及四肢折叠：保留骨骼局部轴，按实际父级逐段对齐，保存前检查躯干和四肢方向。旧版生成的校准需要重做；原文件会备份为 `.before-tpose-fix.bak`。按 P 也会取消预览并解冻。
- 校准保存在插件旁的 `mmd/<骨架指纹>.rig.json`。指纹包含角色、骨名、父级和网格绑定矩阵；骨架变化后重新校准。表情绑定独立保存在 `mmd/morph-mapping.json`。现有 `.poser.json` 格式保持兼容。

## 播放控制

支持播放、暂停、停止恢复、前后逐帧、进度拖动、`0.25–2` 倍速和循环。VMD 使用 30 FPS 帧号，运行时按单调时钟采样。默认一倍速、不循环；自然结束保持末帧。暂停后可在原姿态库保存当前身体姿态。

**动作 IK** 可在播放或暂停时切换，当前帧立即生效，进度和播放锚点保持不变：

- **跟随动作**（默认）：遵循 VMD 的 IK 开关轨道；内置骨架没有对应 IK 动作轨道时保留 FK。
- **强制开启**：覆盖动作中的关闭标记，启用所选骨架已有的脚部、脚尖及其他受支持的 IK 链；无对应关键帧时使用骨架的静止 IK 目标。
- **强制关闭**：停止源骨架和游戏目标骨架的 IK 求解，按动作的骨骼旋转播放。仅口型/眼神播放不会因开启 IK 而控制身体。

已有脚 IK 轨道但没有开关轨道时，“跟随动作”默认开启该 IK。如果动作已把弯膝烘焙到骨骼旋转，却仍保留静止脚 IK 目标，可手动选“强制关闭”。面板显示左右腿本帧是否进行了 IK 求解。不会读取说明或按文件名切换。

## 动作幅度与腿部适配（0.4.11）

展开 **动作幅度（全身 / 分部位）**：全身幅度统一调整；躯干、头颈、左右臂、左右手与手指、左右腿、左右脚与脚尖可分别调整。开启 **左右联动** 时先将左侧数值复制到右侧，之后修改任意一侧会同步另一侧。

各滑条范围 0–200%，实际系数为 **全身 × 部位**，例如全身 80%、左腿 50% 得到左腿 40%。默认均为 100%，维持原动作；0% 回到对应部位的源骨架对齐基准姿态。每个部位可单独复位，也可全部恢复 100%。播放和暂停时均可调整，隐藏面板后继续生效。

幅度在 IK 和重定向之后作用于局部关节旋转，保留骨长。它不改变根位移、时间轴、音乐、表情权重和眼神轨道；移动范围仍由 **位移比例**、**原地播放** 和 **高度修正** 控制。动作幅度能辅助调整姿势，但不提供模型碰撞检测，不能保证消除穿模，腿脚的调整也可能改变脚底接地。

停止并恢复后，可用 **骨架适配 / 追加骨骼 → 保存适配预设** 一并保存幅度；载入旧预设时幅度为 100%。新开动作和切换角色保留当前手动数值，不按文件自动选择。

修复目标腿 IK 使用整体位移比例缩放髋到脚距离的问题。现在从源腿提取弯膝角与髋到脚方向，使用目标角色自身大腿/小腿长度重建目标，避免因位移比例变大而将膝盖拉直。不同模型仍需通过 PMX 参考、骨架基准、映射与手动 IK 模式适配；0.4.17 可额外开启下述地面接触辅助。

0.4.12 修复多数动作中手指末节反折：末节现在继承前一节的基准对齐修正，再叠加自身动作旋转。保留真实骨骼局部轴、中间辅助骨和原动作弯指，不将末节锁直，也不改变手部幅度设置。两节拇指的映射回退同样处理；映射到非手指链的自定义骨骼不套用此规则。无需重做既有校准。

0.4.2 增加独立快捷键，隐藏面板后仍可使用，在主窗口 **快捷键（可改）** 中重新绑定：

| 默认快捷键 | 操作 |
|---|---|
| Ctrl+F5 | 播放 / 继续 |
| Ctrl+F6 | 暂停，保持姿态 |
| Ctrl+F7 | 停止并恢复播放前状态 |
| Ctrl+F8 | 重置到动作首帧并暂停，保留本次播放锚点 |

0.4.7 在 MMD 播放器顶部直接显示四个播放快捷键及界面显示/隐藏键，主面板的快捷键一览也同步显示。提示使用当前配置，改键后立即更新；隐藏界面后播放快捷键仍有效。

角色的专用道具、武器挂点和道具特效节点在校准预览及播放期间自动隐藏，停止时恢复原可见状态。识别范围限定在当前角色下的专用节点，身体、头发、衣服保留；游戏中新增的道具也会定期检查。自定义模型采用其他命名的道具仍需适配。

主窗口默认允许拖动标题栏。**锁定窗口**可固定位置，**重排窗口**恢复初始排列；位置和尺寸保存在插件旁 `poser_layout.ini`，重启后继续使用。

位置与朝向以开始播放的角色模型根节点为锚点；循环不会累积位移。**原地播放**锁住水平位移，保留上下起伏；**高度修正**调整整体高度。默认让游戏头发、衣物物理继续运行，可勾选冻结。

关闭或隐藏面板仍会播放。**停止并恢复**还原开始前的位置、姿态、冻结状态、表情驱动和物理组件开关。播放及暂停期间，手工骨骼编辑、姿态载入和表情滑条暂时禁用；按 **P** 会先停止播放器再解冻。切换角色、刷新骨架、对象失效或退出插件会终止当前会话。

0.4.13 修正冻结状态下的角色切换流程：切走时从内存保存姿态，释放旧实例的冻结控制，再捕获新角色；旧对象已销毁时只清理引用。切回已保存的角色后重新采集组件并恢复其冻结姿态，新角色保持默认状态。切换期间暂停插件骨骼写入，恢复组件时保留原先的启用 / 禁用值。表情回调与角色缓存重置互斥，繁忙时直接执行游戏原回调，避免阻塞游戏线程。

## 地面与裙摆碰撞辅助（0.4.25）

展开 **地面与裙摆碰撞辅助**。**脚底防穿地默认关闭**，不改变已有动作；开启后在动作幅度调整之后追加脚部修正，尽量保持腿部骨长、原有脚部姿态和抬脚 / 跳跃。它是独立约束：即使动作 IK 设为强制关闭，开启脚底防穿地仍会运行接触修正。

- **探测游戏地面**：在游戏表情更新回调中以最多 20 Hz 查询地面，播放线程只读采样结果。忽略触发器、角色模型自身的碰撞体、墙面和过陡表面。接口不兼容、命中缓冲区满、结果过期或脚已离开采样区域时不修正，并显示状态。没有可用的游戏回调时也不会从工作线程查询物理。
- **固定平面（起始脚底）**：使用播放开始时根据校准骨架估计的水平面，不识别场景台阶；可用 **地面高度微调** 修正。场景探测失败时不会自动切换到这个估计平面，需手动选择。
- **鞋底厚度补偿**：骨架没有鞋底网格厚度，按角色鞋型调整。**接触修正强度**控制影响程度，**最大抬脚修正**限制单次修正范围；超过范围或腿无法到达时会提示残余穿地。整体严重下沉仍需调整播放器的 **高度修正**。
- **脚部跟随坡面**：接近地面时叠加坡度修正，保留动作本身的脚部旋转。不向下拉住抬起的脚，不自动锁定脚的水平位置。拖动、暂停和循环均从原始采样姿态重新计算，避免累积偏移。
- **BBC 原生同帧碰撞**：默认开启。BBC 的跨帧路径可读取 Animator 内部缓存，而播放器直接修改骨骼 Transform；为让碰撞读取同一套动作，播放期间通过原生接口切换为直接读取 Transform 的模拟路径，在 BBC 求解前提交当前动作，随后由游戏完成碰撞、布料模拟和写回。同步切换跨帧与动画缓冲两个模式，保留原生帧初骨骼恢复，避免将上帧布料结果反复当作动画输入。暂停时布料继续模拟；停止、关闭选项或禁用插件后，在下一次 BBC 更新中恢复原调度。该开关影响全场景 BBC 调度，可能增加 CPU 开销。不会另写布料求解器，也不手动调用模拟 Job。
- **当前角色使用完整物理权重（含尾巴）**：默认开启，仅在 BBC 接管时生效。对当前角色已启用的 BBC 组件，将模拟及混合权重临时设为 1，避免沿用待机或技能动画留下的低权重。不会启用隐藏、禁用的组件；关闭、停止或换人时恢复原值。可关闭此项保留原权重作对照。展开 **当前角色 BBC 状态（含尾巴）** 可查看头发、尾巴和衣物的运行、写回及裁剪状态。
- **裙摆碰撞增强**：保留边碰撞开关；**手动调整碰撞体尺寸默认关闭**，保留原版胶囊尺寸。需要时再开启大腿根扩张、半径倍率、长度倍率及锥形调整，过大可能撑起裙摆。冻结衣物后不会动态避让大腿，需取消 **冻结头发 / 衣物** 才能观察碰撞效果。
- **补齐腿部原生碰撞**：默认开启，仅在 BBC 接管期间对已启用、有碰撞设置的裙摆生效。使用该裙摆登记的大腿胶囊半径和当前角色骨长，添加覆盖大腿、膝盖和小腿的临时 BBC 胶囊；**腿部碰撞余量**默认 0.015，可调为 0–0.06，过大会撑开裙子。不会修改腿部动作、尾巴或原有胶囊。关闭、停止、换人时仅移除插件添加的列表项，等待原生求解器释放后删除临时组件。面板分别显示已提交和原生实际登记数量；不兼容的骨架或接口会跳过。
- **裙摆边碰撞**：默认开启，对支持的裙布向游戏请求 Edge 模式，检测布料节点之间的连线，减少只检测节点时的漏碰撞。可随时关闭以恢复该裙布原有模式；不会把原本关闭碰撞的组件强行开启，也不作用于不支持 Edge 的弹簧型布料。开销高于节点碰撞。面板逐件显示请求或不支持的状态；“已请求”不代表已经完成画面验收。

0.4.19 按腿骨层级识别胶囊，不再用局部中心横坐标判断。支持多个裙摆组件，共用碰撞体只调整一次；每个对象单独核对设置接口与字段类型，保留原本两端半径。面板显示裙摆组件、检查碰撞体、实际调整数量；手动尺寸调整开启时，**实际调整为 0 表示没有调整胶囊**；保留原尺寸时为 0 是正常状态，不代表 BBC 未运行。未挂在腿骨层级且无法按骨名识别的特殊碰撞体会跳过。

裙摆初始化未就绪时有限重试；重复调整使用同一份原始参数，不叠加扩张。关闭增强、解冻或结束非冻结会话时恢复原尺寸、锥形开关和碰撞模式；不会修改碰撞体中心，碰撞体或布料设置被游戏替换后不会把旧参数写入新对象。原生布料的固定顶点、运动约束、蒙皮、碰撞体覆盖范围和快速移动仍会限制避让效果，不能保证完全消除穿模。面板与诊断接口显示 BBC 实际运行、跳过写回、模拟权重，以及原生运行时参数中的碰撞模式，区分“参数已请求”和“求解器已采用”。0.4.23 实测仍有尾巴静止和穿模；0.4.24 已实测到裙摆、尾巴在运动，但该长裙仍穿模；0.4.25 补充原生腿部覆盖，并显示动画距离限位和背面限位状态，视觉效果仍需逐角色对照验收。

停止后可随适配预设保存以上设置，不保存本机场景的绝对地面位置。此功能不实现手臂 / 身体避让、墙体阻挡、衣物网格与地面的碰撞，也不导入 PMX 刚体和物理。当前仍需游戏内验证不同角色和场景。

## 音乐同步与更新频率（0.4.9）

展开 **音乐同步 → 选择音乐**，手动选择 WAV、MP3、M4A 等 Windows Media Foundation 可解码的音频。停止并恢复后可以更换或移除音乐。音频在工作线程解码，失败保留原音乐；解码后 PCM 限制为 256 MiB，约 23 分钟。文件选择仅保留在本次运行中，不自动按 VMD 文件名寻找音乐。

音乐随播放/继续、暂停、停止、逐帧、进度拖动、重置和循环同步；拖动与逐帧时静音并暂停，继续时从对应位置播放。音乐短于动作时，音乐结束后动作继续；动作结束时音乐停止。切换角色或关闭插件也会停止声音，已选择的音乐可以继续使用。无需选择音乐也能正常播放动作。

- **随动作播放音乐**：可随时开关。
- **音乐音量**：仅调整插件音乐，不改游戏音量。
- **音乐偏移（秒）**：正值让音乐晚开始，例如 `2` 表示动作第 2 秒才播放音乐开头；负值从音乐中途开始，例如 `-2` 表示动作开头对应音乐第 2 秒。可补偿素材前奏、编码填充或设备延迟。
- **播放速度**同时控制音乐的采样速度；当前会改变音高，不提供保持音高的时间拉伸。

动作使用单调时钟，音频独立连续播放，仅在继续、跳转、循环或时钟偏差超过 100 ms 时重新对齐。UI 的 30 FPS 帧号是 VMD 时间单位；骨骼插值支持小数帧，不限制画面只能每秒更新 30 次。

动作更新独立于面板绘制。播放器尝试使用游戏帧回调，并通过帧号去重；回调不可用时使用独立计时，慢帧直接采样当前时间，不补跑积压帧。具体驱动来源以面板为准。

播放器显示 **跟随游戏帧 / 独立计时**、实际更新 Hz、最长间隔、最大更新耗时和编辑占用次数。游戏渲染管线可能不触发该回调，不能仅凭“hook 安装成功”判断已与游戏帧同步。需在游戏中对照这些数值检查；目前不能保证所有渲染管线均已与背景帧同步。隐藏面板后仍正常播放音乐与动作。

音频 API 依据 [Media Foundation 解码文档](https://learn.microsoft.com/en-us/windows/win32/medfound/tutorial--decoding-audio) 与 [XAudio2 声音销毁生命周期](https://learn.microsoft.com/en-us/windows/win32/api/xaudio2/nf-xaudio2-ixaudio2voice-destroyvoice) 实现；帧回调签名对照 [Unity Camera 参考源码](https://github.com/Unity-Technologies/UnityCsReference/blob/master/Runtime/Export/Camera/Camera.bindings.cs) 和 [Unity 2021.3 SRP 入口](https://github.com/Unity-Technologies/UnityCsReference/blob/2021.3/Runtime/Export/RenderPipeline/RenderPipelineManager.cs)。

## 口型、表情与眼神

**追加口型 / 表情 / 眼神**只导入表情和 `両目/左目/右目` 轨道，与主动作共用时间轴。后追加文件替换同名的完整轨道，其余轨道保留。也可以直接打开只有表情的 VMD。

`あ/い/う/え/お` 自动对应游戏五个口型，眨眼、微笑、眉毛等复用现有 SMC 通道。在 **表情映射** 中可手动绑定未匹配名称并调整强度。SMC 尚未就绪时身体动作仍会播放，面板显示表情状态。

0.4.16 修正表情任务回调的返回数据与参数转发。启动时先检查游戏接口是否匹配；不兼容时保留游戏原表情流程并停用插件表情接管，身体播放器仍可使用。

展开 **导入报告**查看未映射轨道、无目标人体作用的辅助骨及不支持的约束。有 PMX 元数据时会明确标记材质表情。角色没有对应表情通道时，不能复现该效果。

## 骨架适配与準標準骨（0.4.8）

在 **骨架适配 / 追加骨骼** 中先停止动作，再编辑，最后点击 **应用适配**。这是独立于角色校准的源骨架设置，切换预设不需要重新校准角色。未应用修改可撤销；清空适配也需要点击应用才生效。

- **準標準骨补全**：手动补全总父级、Groove、上半身2、腰/腰取消、肩 P/C、腕捩/手捩及 1/4、1/2、3/4 附加骨、脚 IK 父级、足 D/膝 D/踝 D/足先 EX。另可增加独立操作中心和上半身1。已有同名 PMX 骨骼保留其定义。
- **自定义追加 / 插入骨骼**：设置名称、父级、静止位置参考与偏移，或插入到某骨之前；可继承另一骨骼的旋转/位移并调整正负比例。追加的是播放器源骨架中的虚拟骨，参与父级与附加变换计算。
- **动作轨道 → 源骨骼**：为源骨骼指定 VMD 中的轨道，可筛选轨道名、恢复同名默认值或忽略输入。重命名的 IK 控制轨道会使用对应名称的 IK 开关。
- **源骨骼 → 角色部位**：为 55 个人体部位指定源骨骼，或选择不控制。足 D/EX 选项会给腿、膝、踝、脚尖设置默认 D/EX 映射，手动部位映射优先。
- **保存 / 载入适配预设**：使用 `.mmdrig.json`，默认目录 `plugin/mmd/rig-presets`，同时保存 A/T 基准与手动 IK 模式。不会读取 README、相邻说明或按动作文件名自动选预设。工作线程读取、写入；错误配置保留原设置。

随版本附带 `未完成婚姻論-Tda-起始配置`、`未完成婚姻論-火花-起始配置`、`準標準骨补全` 三份手动预设。打开对应 VMD 后，在适配面板点击 **载入适配预设** 选择即可；Tda 起始配置启用足 D/EX，火花版另启用上半身1和腰取消。它们是手动适配的起始设置，需在游戏里检查所用角色并按实际效果调整。

内置骨架预设需要先切回内置骨架；PMX 预设需先选择骨名列表匹配的 PMX 参考。预设不保存本机素材路径，角色变更后仍使用当前选择；文件不会自动加载。自定义骨骼最多 256 个，重复名、缺少依赖、父级/附加变换/位置参考循环和非有限数值会拒绝应用。面板追加后先应用，再选择该骨作为下一个新增骨的父级或映射目标。

参照 [準標準ボーン插件的公开移植实现](https://github.com/hkrn/nanoem/blob/main/emapp/plugins/ssb/ssb.cc) 核对父级、取消旋转和 D/EX 附加关系。这里不编辑 PMX 模型、不创建游戏 Transform，也不重新分配网格权重；分段捩骨不等于游戏皮肤权重已适配。操作中心是独立视图控制骨，默认不驱动人物；专用手持道具轨道不会自动改成人体手部。局部位移参与源骨架计算，游戏人体保持既有骨长，整体位移和 IK 目标按既有规则转换。未支持的骨骼仍列在导入报告中。

## 支持边界

“动作原始姿态”仅手动选择 **标准 MMD / A 姿** 或 **提取动作 / T 姿**，默认 A 姿。0.4.6 已移除读取 README、说明文件和自动选择骨架的逻辑；打开新动作或追加表情时保留本次运行中手动选择的姿态和 IK 模式。所选 PMX 优先，停止并切回内置骨架后可改 A/T 姿。T 姿基准包含平行手指、原点中心骨；它与角色校准分别设置，无需因此重新校准角色，也不会缩小动作原始旋转。

不包含 MMD 相机、灯光、多角色同步、模型导入和 MMD 物理。游戏自身物理可以保留。PMX 外部父级未实现，物理后骨骼按无物理方式计算；超过 64 次迭代的 IK 会限制迭代次数并写入报告。PMX 局部轴作为骨架元数据读取；VMD 四元数按 MMD 模型坐标解释，固定轴约束在求解时执行。

动作自带的专用肘部 IK、服装、发丝、表情材质与非标准辅助骨可能没有游戏侧对应物。选择匹配的 PMX 可提高源骨架计算准确度，仍需以实际画面检查手臂方向、脚底和手指。

## 切换角色与本机接口

切换角色会结束当前播放或校准预览，保留已经打开的动作。新角色骨架加载后可以重新校准或播放；播放会优先读取该角色已有校准。若面板显示正在等待骨架，可点击主面板“刷新骨骼”重新捕获。不会删除旧角色的校准文件。

原 HTTP 姿态写接口在播放器占用时返回 `409 Conflict`。只读 `GET /api/mmd/status` 可查询播放、校准、表情状态和导入报告；`adaptation` 返回当前已应用的骨架适配，`rig_bones` 是补全后的源骨数；`source_preset` 为 0=A 姿、1=T 姿，`ik_mode` 为 0=跟随动作、1=强制开启、2=强制关闭。`character_ready` 表示当前选择的角色骨架已就绪，`calibrated` 仅表示当前实例/骨架版本的校准。

现有本机控制文件 `plugin/poser_control.txt` 增加下列 UTF-8 命令，用于可复现验收；每次执行后移除控制文件，先等待导入完成再发播放命令：

```text
mmd_load <VMD 路径>
mmd_music <音乐路径>
mmd_append <口型/表情/眼神 VMD 路径>
mmd_pmx <PMX 路径>
mmd_rig_load <适配预设路径>
mmd_rig_save <适配预设路径>
mmd_play
mmd_pause
mmd_seek <VMD 帧号>
mmd_stop
mmd_reset
mmd_calibrate_auto
mmd_calibrate_preview
mmd_calibrate_confirm
```

不同角色与动作仍需在游戏中检查实际效果，解析成功不代表所有轨道均已适配。
