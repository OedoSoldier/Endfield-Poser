## 1. 安装

从 [Releases](https://github.com/honxi1/Endfield-Poser/releases) 下载 `EndfieldPoser-v0.2.1.zip`，
把里面的文件按下面放到游戏目录：

| 包内文件 | 放到 |
|---|---|
| `d3dcompiler_47.dll` | 游戏根目录（**先备份游戏自带的那份**） |
| `vulkan-1.dll`（可选） | 游戏根目录 |
| `plugin\poser.dll` | 游戏根目录的 `plugin\` |
| `plugin\poser_config.txt` | 游戏根目录的 `plugin\` |

> 📁 **看清楚是 `plugin\`（单数），不是 `plugins\`（复数）**。
> 游戏目录里两个都有：`plugin\` 是插件目录（我们的东西放这里，没有就自己建一个），
> `plugins\` 是游戏自带的 Qt 插件目录（`imageformats/`、`platforms/` 等），放错不会生效。

> ⚠️ **必须用 Hypergryph 启动器启动游戏**。直接双击 `Endfield.exe` 会在 IL2CPP 运行时初始化
> 完成前注入，触发 Unity GC 致命错误（弹 `Threads explicit registering is not previously enabled`），
> 游戏卡死。这是唯一一条硬性要求。

## 2. 第一次启动：确认插件活着

启动游戏后，在游戏目录找两份文件：

- `plugin\poser_log.txt` —— 日志，正常启动应该能看到这几行（顺序即执行顺序）：

  ```
  [POSER] === Endfield Poser v0.2.1 attached ===
  [CFG] gui_toggle_key=... 
  [POSER] Resolving IL2CPP...
  [POSER] IL2CPP resolved. Initializing game hooks.
  [OK] PlayerController.SetMainCharacter hooked
  [SMC] ... / [GUI] ... / [WEB] ...
  ```

  **只要卡在 `Resolving IL2CPP...` 没有再往下，就是没走启动器**——关掉重开即可。

- `plugin\poser_log.txt` 里的 `[GUI] ImGui initialized, panel ready` 出现后，按 **F12** 就能呼出面板。

面板一共有四个窗口（默认位置，可拖动，勾「图钉」后锁定位置）：

| 窗口 | 作用 |
|---|---|
| Endfield Poser（左上） | 主控制：冻结、骨骼显示、人物位置、快捷键 |
| 骨骼参数（中上） | 选中骨后的旋转/位置参数 |
| 姿态库（左中） | 姿态预设的保存/载入/删除 |
| 形态键（右上） | SMC 表情滑条 |

还有一个 WebUI：浏览器打开 `http://127.0.0.1:18923`。

## 3. 冻结：把角色定住

**按 F11（或点主面板的 `Freeze Character`）。**

冻结做了三件事：

1. 关掉 Animator，角色停在当前帧；
2. 抑制 FinalIK / Grounder 等会写骨骼的组件；
3. 按选项钉住头发、裙子、飘带等从骨（主面板「冻结飘带/裙子/头发」，默认开）。

再按一次 F11 解冻，一切恢复。**摆姿必须在冻结状态下做**——没冻结时游戏每帧都会把骨骼覆盖回去。

### 切换角色时会怎样

冻结状态是**按角色记住**的，所以可以逐个角色摆姿：

- 冻结 A → 切到 B：**B 保持默认**（不冻结、正常活动）；
- 摆好 B 并冻结 → 切回 A：**A 恢复你离开时的姿势**（它的 Animator/IK 会被重新压制）；
- 后台已经冻结过的角色不会被游戏重新拉走，会一直保持你摆好的样子；
- 只有**当前角色**能编辑（骨架列表、从骨、形态键都跟着当前角色）；要改别的角色，先切过去。

日志里能看到 `[CHAR] saved frozen state for ...` / `[CHAR] restoring frozen state for ...`，
以及 `[CHAR] '...' has no saved frozen state -> leaving it unfrozen`。

## 4. 摆姿势：点、拖、拉

### 点选骨骼

- 默认只显示 **humanoid 骨**（55 根）——干净，够用；
- 要选手指、头发这类，勾主面板的 **「全量骨骼(微调)」**；
- 3D 视图里关节会画成小圆点，**鼠标靠近会出白色提示圈**，点一下就选中（变黄）；
- 选中骨上会出现**旋转盘**，拖外圈即可旋转；点空白处取消选中。

### 参数面板（精调）

选中骨后，在「骨骼参数」窗口里能：

- **旋转**：一条滑条（可拖）+ 一行输入框（可键入具体角度，单位是度）；
- **位置**：同上，小数位更细；
- **步长 + XYZ ± 按钮**：点一下走一个步长，适合"再转 5 度"这种微调；
- **复位旋转 / 复位位置 / 全部复位**：把该骨恢复到基线（humanoid 骨回到 A-pose，从骨回到冻结瞬间）；
- **锁定**（humanoid 骨）：锁定后快照恢复/镜像等操作会跳过它。

> 输入框要打字：先让光标出来（见 [第 9 节](#9-面板操作与输入模型)），点进输入框直接敲，回车或点到别处即生效。

### 「全部重置」

主面板的 `全部重置` 会把**所有骨（含从骨）恢复到你按 F11 冻结那一刻的姿态**——
摆乱了想重来，点它就行，不用解冻重冻结。

## 5. 头发/裙子/飘带（从骨）

这些"从骨"是挂在骨架上的动态链（不是 humanoid 55 根之一）：

1. 勾主面板 **「全量骨骼(微调)」**，头发/裙子/飘带的骨点就会出现，可以直接点选、旋转；
2. 冻结时它们被钉在冻结瞬间的姿态；**你手动改过的那根会以你的改动为准**，不会被每帧回写打回去；
3. 想让某条链回到冻结时刻的样子：选中它 → `复位旋转`。

> 从骨里的 `Nub`/`Twist`/`corrective`/碰撞体/表情骨等内部骨会被自动过滤，不会出现在画面里。

## 6. 调整人物整体位置

冻结后主面板会出现 **人物位置 (Root XYZ)**：

- 滑条拖动、输入框键入具体值，或用 **步长 + XYZ ±** 按钮微调；
- 适合把角色挪到取景中心、或做"离地/下沉"的效果。

## 7. 表情

「形态键」窗口分两段：

- **游戏原生表情 (SMC)**：本作面部由骨骼变形驱动（SkeletalMorphCore），这里列出**口型**与
  **表情**滑条（微笑、生气、眨眼…）。拖动即生效（需在冻结态），`全部归零` 复位。
- **BlendShape**：本作网格上没有 BlendShape 目标，**这一段为空是正常的**。

**注意（已知限制）**：表情（SMC 权重）不写入姿态预设，也**不能跨角色通用**——
不同角色的骨架与 morph 表不同，套用会得到错位或夸张的脸。表情请在当前角色上调。

## 8. 保存与套用姿态预设

「姿态库」窗口：

| 按钮 | 说明 |
|---|---|
| 保存预设 | 用「命名」里的名字保存；留空则自动编号 `Pose_001` |
| 覆盖保存 | 覆盖列表里选中的那条 |
| 加载 | 套用选中预设到当前角色 |
| 删除 | 删除选中预设 |
| 刷新列表 | 重新扫描目录 |

存储位置：`<游戏目录>\plugin\poses\*.poser.json`（面板底部也会显示当前路径，
可用配置项 `default_pose_dir` 改）。

**「不保存/不套用表情」默认勾选**：姿态只含身体与从骨，跨角色套用时脸不会被弄乱。
想让姿态带上眼睛/下巴（**仅供同角色使用**）就取消勾选。

推荐工作流：冻结 → 摆好姿势 → 命名保存 → 换姿势继续保存 → 需要时从列表里加载。

## 9. 面板操作与输入模型

插件用的是"覆盖层 + 真穿透"模型，规则很简单：

| 状态 | 鼠标/键盘归谁 |
|---|---|
| 没按 Alt（光标被游戏锁住） | **全部归游戏**，正常走位、转镜头 |
| 按住 Alt（或游戏自己放开光标，例如摄影模式） | 指针在面板/关节上时归面板，其余仍然归游戏 |
| 点进输入框 | 键盘临时归面板，可以打字；点到别处立刻还给游戏 |

所以：**要操作面板，先按住 Alt**；松开 Alt 面板依然可见，只是不再吃鼠标。

面板右上角有「图钉」，勾上后所有窗口位置锁定（防止拖旋转盘时把窗口带跑）。

## 10. 排查：出问题先看这里

**先看 `plugin\poser_log.txt`**，绝大多数问题日志里都有答案。

| 现象 | 原因 / 处理 |
|---|---|
| 游戏启动就卡死弹 GC 错误 | 没用启动器启动。关掉，走 Hypergryph Launcher 重开 |
| 日志停在 `Resolving IL2CPP...` | 同上 |
| 面板呼不出来 | 确认按的是配置里的键（默认 F12）；确认日志有 `panel ready` |
| 点不动面板/骨骼 | 没按 Alt；或指针没落在关节 14px 内 |
| 鼠标"消失" | 游戏把系统光标隐藏了，插件会补一个软光标；若仍看不见，按住 Alt 试 |
| 骨骼数为 0（面板显示 `Bones=0`） | 角色还没加载完，或不在有角色的场景；进场景后按「刷新骨骼」 |
| 改完姿势被弹回去 | 没冻结；或该骨被游戏 IK/布料覆盖（冻结会抑制它们） |
| 表情滑条没反应 | 先在冻结态；若仍无反应，看日志里 `[SMC] slider ...` 与 `[SMC] weights sum=...` 两行 |
| 姿态套到别的角色上脸乱了 | 姿态默认不含表情；若旧文件带表情数据，载入时会跳过。已乱的脸请解冻→重新冻结拿干净快照 |

## 11. 速查表

| 操作 | 键 / 位置 |
|---|---|
| 呼出/隐藏面板 | `F12`（`poser_config.txt` 的 `gui_toggle_key`） |
| 冻结 / 解冻 | `F11` |
| 面板交互 | 按住 `Alt`（或游戏自己放开光标时直接点） |
| 移动人物 | 主面板 人物位置（滑条/输入/±） |
| 全部重置（回冻结瞬间） | 主面板 `全部重置` |
| 姿态保存位置 | `<游戏目录>\plugin\poses\` |
| 日志 | `<游戏目录>\plugin\poser_log.txt` |
| WebUI | `http://127.0.0.1:18923` |

配置项（`plugin\poser_config.txt`）：

```
gui_toggle_key=VK_F12     # 支持 VK_F12 / F12 / 0x7B
freeze_key=VK_F11         # 冻结 / 解冻（可改，写法同上）
click_through=1           # 1=覆盖层常驻并真穿透（推荐）；0=按住 Alt 才显示面板
default_pose_dir=plugin\poses
```
