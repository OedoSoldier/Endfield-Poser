# 快速教程

先按[安装说明](../README.md#安装更新与卸载)完成安装，再进入可操作角色的场景。

## 打开与整理面板

按 **L** 显示或隐藏面板；需要鼠标光标时按住 **Alt**。拖动标题栏可以移动窗口，拖不动时取消 **锁定窗口**。点击 **重排窗口** 可恢复初始布局。

## 手工摆姿并保存

1. 按 **P** 冻结当前角色。
2. 在画面或骨骼面板中选中骨骼，用旋转工具或参数调整姿势。
3. 如需固定并编辑头发、裙子等部位，勾选 **冻结飘带／裙子／头发**；该选项默认关闭。
4. 在 **姿态库** 输入名称并保存，之后选中姿态即可载入。
5. 按 **P** 解冻，恢复游戏动作。

姿态库默认不保存或套用面部表情。载入其他角色的姿态后，可能需要微调手脚。

## 眼睛朝向

在 **表情 → 眼睛朝向** 中选择 **手动方向** 或 **自动看向镜头**，冻结角色或播放动作后生效。左右、上下滑条可调整方向，看向镜头时用于微调；**方向归零** 清除偏移。左右以角色自身为准。

播放、暂停及隐藏面板时仍生效，支持游戏镜头与 MMD 镜头。切回 **跟随游戏 / 动作** 恢复原有眼神；换角色或刷新骨架会复位。只改变眼球方向，眉毛、眨眼和口型仍按原设置播放；转动有角度限制，镜头在身后时回到正前方。

若角色缺少虹膜参考点，面板会提示使用手动方向；未读取到镜头时会暂时恢复原眼神。
自动看向镜头会保留角色原本的双眼布局；镜头靠近时限制双眼汇聚幅度，避免过度对眼。

## 手动调节 MMD 表情

在 **表情** 面板顶部选择 **MMD 模式**，按 **P** 冻结角色，即可按 **眉毛、眼睛、嘴部、其他** 调节中文表情滑条，无需载入 VMD。多个表情可以叠加；支持单项、本组、全部归零和整体强度调整。悬停标签可查看原始 MMD 名称。

优先使用当前角色的专属映射，可勾选 **缺失时使用固定映射**；不可用的表情会标出。切回 **游戏模式** 恢复切换前的游戏滑条设置；隐藏面板保持表情。播放或暂停动作时手动滑条暂不可用，停止后恢复此前手动设置。换角色或刷新骨架会清空手动 MMD 表情。

## 播放一个 MMD 动作

1. 勾选 **MMD 播放器**，点击 **打开 VMD**。
2. 首次使用当前角色时完成校准；自动校准失败可使用 **手动 T 姿预览**。
3. 点击 **播放**。需要配乐时，在 **音乐同步** 中选择音乐；镜头文件在 **MMD 镜头** 中选择。
4. 用进度条查看动作，暂停后可在姿态库保存当前身体姿态。
5. 按 **L** 隐藏面板，用快捷键继续控制播放。

更换角色会结束当前播放，已打开的动作保留。播放或暂停期间，手工骨骼编辑、姿态载入和普通表情滑条暂不可用；需要编辑时先 **停止并恢复**。

## 默认快捷键

| 按键 | 操作 |
|---|---|
| `L` | 显示／隐藏面板 |
| `P` | 冻结／解冻；播放中先退出播放器 |
| 按住 `Alt` | 呼出光标操作面板 |
| `Ctrl+F5` | 播放／继续 |
| `Ctrl+F6` | 暂停并保持姿态 |
| `Ctrl+F7` | 停止并恢复播放前状态 |
| `Ctrl+F8` | 回到首帧并暂停 |

在主面板 **快捷键（可改）** 中重新绑定。已有设置优先，以面板显示为准；避免使用与其他插件冲突的按键。
