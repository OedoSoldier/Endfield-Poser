## 安装与进入场景

1. 退出游戏，完整解压发布包；源码用户先运行 `build.bat`。
2. 双击 `安全安装.bat`，选择含 `Endfield.exe` 的游戏根目录，安装或直接更新。
3. 启动游戏，使用窗口化 / 无边框模式，阅读首次显示的[用户协议](user-agreement.md)，确认后进入可操作角色的场景。可通过鹰角启动器、EFMI 或直接运行游戏启动；验证范围见 [README](../README.md#启动兼容性)。
4. 按 **L** 打开面板，必要时按住 **Alt** 操作光标。

## 手工摆姿

1. 按 **P** 冻结角色，选择骨骼，用旋转盘或参数面板调整。
2. 需要调整头发、裙子等从骨时，开启相关冻结选项再编辑。
3. 在姿态库输入名称并保存。姿态默认不带面部骨，避免跨角色错脸。
4. 按 **P** 解冻。换人会保存本次运行中的角色姿态，切回后重新捕获恢复。

拖动标题栏排列窗口；不能拖动时取消 **锁定窗口**，也可用 **重排窗口** 复位。

## 播放 MMD

1. 勾选 **MMD 播放器**，打开自己的 VMD 文件。
2. 首次使用该角色时完成自动校准；失败则通过 **手动 T 姿预览** 修正并确认。
3. 按 **Ctrl+F5** 播放，**Ctrl+F6** 暂停，**Ctrl+F7** 停止恢复，**Ctrl+F8** 回到首帧并暂停。
4. 可追加口型 / 表情 / 眼神、手动选择音乐，或调整 IK、源骨架和全身 / 分部位幅度。
5. 按 **L** 隐藏面板继续播放。以面板实际显示的快捷键为准。

## 更新与卸载

再次运行安装向导即可更新，无需先卸载。卸载保留配置、布局、校准、姿态和备份；共用代理与旧安装的处理规则见 [README](../README.md#安装更新与卸载)。

遇到问题时记录版本、操作步骤及 `plugin/poser_log.txt` 中相关片段，通过仓库 issue 反馈。
