# 0.5.42 — Blender 缩放关键帧与镜头转场修复（预发布）

## 更新内容

- **骨骼缩放关键帧**：Blender 联动 0.2.9 支持记录关节缩放、实时同步及导出播放；修正层可以恢复原始缩放，停止播放后恢复角色原状态。建议使用等比例缩放；非等比例缩放在游戏中的效果可能与 Blender 不同，不支持零或负数缩放。
- **镜头转场**：导出的镜头保留硬切，避免游戏在转场之间插入一帧过渡画面；同时修正镜头修正层中可能造成突然翻转的旋转关键帧。
- **动作重新加载**：衣物辅助骨增加、减少或排序变化时，重新对应动作使用的骨骼，减少“骨骼已改变”误报。角色或实际动作骨骼不兼容时仍会提示。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击包内 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选 **安装本地包**；也可通过安装向导的 **在线安装 / 更新** 获取新版。
3. 使用 Blender 联动时，保存工程，在 Blender 插件管理中从磁盘安装包内的 **Blender联动插件.zip**，更新后重开 Blender。游戏端与 Blender 插件需要一起更新。

无需先卸载，安装器会备份旧文件并保留配置、姿态和个人校准。附件只提供编译好的标准安装包；安装请选择 **win64.zip**，不要下载 GitHub 自动列出的 **Source code**。

## 旧文件如何处理

- 原有 `.epmotion` 可直接重新加载；如果此前只是辅助骨变化导致误报，无需重新导出。
- 旧镜头工程若已丢失硬切信息，请使用新版联动**重新导入原镜头，再导出 `.epcamera`**，已有修正层会保留。手动制作硬切时，将转场前一个关键帧的插值设为 **常量**。
- 新版导出的动作与镜头需使用 **0.5.42 或以上版本**播放，旧文件仍可读取。
