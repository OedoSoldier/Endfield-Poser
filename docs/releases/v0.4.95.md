# 0.4.95（预发布）

[下载 Windows x64 安装包](https://github.com/OedoSoldier/Endfield-Poser/releases/download/v0.4.95/Endfield-Poser-v0.4.95-win64.zip)

## 更新内容

- 修复陈千语、洁尔佩塔等角色因辅助末端骨而无法自动校准的问题。升级后可在 **高级 → 角色校准** 点击 **重新自动适配**，无需删除手动校准。
- 新增 **按角色 PMX 校准拇指（含归零）**，默认开启，内置 37 个角色的参考，单人、多人共用。关闭后使用游戏原生拇指基准；缺少参考的关节自动保留原生姿态，其他手指和骨长保持不变。
- 修正手指动作旋转基准，减少拇指动作方向偏差。
- 减少停止播放后仍重复执行的后台更新，并修复超长日志的截断问题。

拇指选项可随适配预设保存；参考已编入插件，无需另装 PMX。重置动作仍会保留 VMD 首帧自带的手势。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，解压到游戏目录之外的文件夹。
2. 双击新版包内的 **安全安装.bat**，选择含 `Endfield.exe` 的目录，再选 **安装或更新**。
3. 启动游戏，按 **L** 打开面板，导入 VMD 并播放。

向导自动备份旧文件，保留配置、姿态和用户校准。由 0.4.91 或更早版本升级时，旧身体校准会先备份，再重新自动校准；表情校准保留。

本次附件仅提供编译好的标准安装包，不包含 XXMI 联动。GitHub 自动列出的 Source code 是源码，普通安装请选择上方的 win64.zip。
