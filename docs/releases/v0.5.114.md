# 0.5.114 — 新版游戏兼容与小刻适配

相较上一发布版 **0.5.112**：

- **新版游戏兼容**：更新服装物理增强适配，修复游戏更新后开启增强可能阻断动作和镜头播放的问题。
- **新增小刻适配**：加入专属表情、眼神与拇指校准，接入左右外套的碰撞增强；袖子、尾巴等独立部件保留原有物理。安装包现含 39 份角色表情校准。
- **表情读取修复**：支持小刻等表情数据较多的角色，修正表情基准读取失败；角色数据重载后自动重新绑定，单人与小队成员分别保存和恢复。
- **播放准备修复**：正确处理小刻外套的原有重复碰撞引用；衣物准备失败时取消整批准备并恢复已接管部件，避免留下部分增强状态。

## 安装与更新

1. 完全退出游戏，将上方 **win64.zip** 完整解压到游戏目录之外。
2. 运行 **安全安装.bat → 安装本地包**，选择包含 `Endfield.exe` 的目录；也可在原安装向导选择 **在线安装 / 更新**。
3. 安装器自动备份旧文件，保留配置、姿态和自定义校准。启动后按 **L** 打开面板。

本版继续作为预发布版。Blender 联动仍为 **0.3.2**，已安装该版本无需重复更新。请下载 **win64.zip**；GitHub 自动列出的 **Source code** 不能直接安装。
