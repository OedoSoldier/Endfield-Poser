# Endfield Poser 0.4.16（Windows x64 预发布）

这是 `OedoSoldier/Endfield-Poser` 功能分支的首个预编译发布包，包含摄影摆姿、MMD 动作、口型表情和可选音乐播放。本版修复首次加载角色时可能发生的启动闪退。已有 0.4.13–0.4.15 的用户可直接更新。

## 下载哪个文件

在 [Release 页](https://github.com/OedoSoldier/Endfield-Poser/releases/tag/v0.4.16) 的 **Assets** 中选择：

| 文件 | 用途 |
|---|---|
| `Endfield-Poser-v0.4.16-win64.zip` | 普通用户安装包，含 DLL、安装向导、适配预设和说明，无需 Visual Studio |
| `Endfield-Poser-v0.4.16-source.zip` | 对应本版的公开源码，含构建脚本和依赖，供自行编译 |
| `SHA256SUMS.txt` | 两个 ZIP 的 SHA-256 校验值 |

GitHub 自动附加的 **Source code (zip / tar.gz)** 同样是源码，不含预编译 DLL。动作、PMX 模型和音乐需自行准备，安装包不附带这些素材或任何用户配置。

## 本版更新

- 修正表情任务回调的返回值和完整参数转发，解决本次已定位的首次加载角色闪退。
- 启动时校验游戏回调接口，包括实际的 `UInt32` 参数；不兼容时停止表情接管并保留游戏原表情流程。
- 移除无实际功能的特殊表情任务拦截，保留冻结换人时的对象存活检查和互斥保护。
- 随包提供自动备份的安装 / 更新 / 卸载向导，保留配置、窗口布局、校准、适配预设与姿态。

本分支累计功能还包括：VMD 身体 / 手指 / 眼神 / 口型 / 表情、追加独立表情轨道、可选 PMX 骨架参考、手动 IK 开关与骨骼映射、準標準骨补全、全身与分部位动作幅度、播放快捷键、可选音乐同步，以及手指末节和腿部重定向调整。完整操作见 [MMD 播放指南](../mmd-player.md)。

## 首次安装

1. **正常退出游戏**，确认游戏进程已结束。
2. 下载 `Endfield-Poser-v0.4.16-win64.zip`，右键解压全部文件。打开解压后的 `Endfield-Poser-v0.4.16` 文件夹；不要在压缩包内运行脚本。
3. 双击 **`安全安装.bat`**，输入游戏根目录，例如 `D:\Games\Arknights Endfield`。应能在该目录直接看到 `Endfield.exe` 和 `GameAssembly.dll`；不要选择启动器目录、`plugin` 或 `plugins` 子目录。
4. 选择 **1：安装或更新**，等待成功提示。脚本会备份需要覆盖的 DLL；安装期间不会启动或结束游戏。
5. 经 **Hypergryph Launcher（鹰角启动器）** 启动游戏，使用窗口化或无边框模式，进入可操作角色的场景。不要直接运行 `Endfield.exe`。
6. 按 **L** 打开面板。需要操作鼠标时按住 **Alt**；无法拖动窗口时取消 **锁定窗口**，或使用 **重排窗口**。

安装后的主要文件位置：

```text
游戏根目录/
  Endfield.exe
  GameAssembly.dll
  d3dcompiler_47.dll
  vulkan-1.dll
  plugin/
    poser.dll
    poser-install.json
    poser-backups/
    mmd/rig-presets/
```

`plugin` 是单数；它和游戏自带的 `plugins` 不同。保持解压包内的目录结构，安装向导需要旁边的 `tools/deploy.ps1`。如果代理 DLL 已被其他工具修改，安装器会保留该文件并报错；先确认它的归属，不要强行覆盖。

## 更新与卸载

**更新：** 退出游戏，完整解压新包，运行同一个 `安全安装.bat`，选择原游戏目录和 **1**。无需先卸载；已有配置、布局、校准和姿态保留，同名适配预设不会被覆盖。

**卸载：** 退出游戏，运行 `安全安装.bat`，选择原游戏目录和 **2**。移除 `poser.dll`，按安装记录恢复本工具管理的代理 DLL；配置、姿态和备份保留。其他插件仍需要共用代理时会保留代理；旧安装没有归属记录时仅移除 Poser。

安装记录和备份位于游戏的 `plugin/poser-install.json`、`plugin/poser-backups/`。保留备份便于恢复，不要删除他人的插件文件。手动安装方法和保存位置见 [README](../../README.md)。

## 开始播放 MMD

1. 勾选 **MMD 播放器**，选择 **打开 VMD**，首次使用该角色时完成校准。
2. 自动校准失败时使用 **手动 T 姿预览**，调整并确认后再播放。
3. 按 **Ctrl+F5** 播放；需要音乐时手动选择音频，按需调整时间偏移。不会根据文件名自动选择 IK 或音乐。
4. 按 **L** 隐藏面板继续播放。需要暂停摆姿或停止时使用下表快捷键。

| 默认快捷键 | 行为 |
|---|---|
| `L` | 显示 / 隐藏面板 |
| `P` | 冻结 / 解冻；MMD 占用时先退出播放 |
| `Ctrl+F5` | 播放 / 继续 |
| `Ctrl+F6` | 暂停，保持当前姿态 |
| `Ctrl+F7` | 停止，恢复播放前状态 |
| `Ctrl+F8` | 回到首帧并暂停 |

快捷键可在面板修改；已有配置优先，以面板显示的实际绑定为准。

## 验证与已知限制

- 本版已通过 11 组本机自动测试；实际进入角色场景，并观察到动作与表情驱动启用后持续运行，未复现本次启动闪退。该结果不代表所有角色、动作、连续换人或其他模组组合都已验证。
- 保持预发布状态。游戏更新可能改变接口；表情接口不兼容时，身体播放器可继续使用，表情状态会显示未就绪。
- 游戏帧回调不可用时仍会回退到独立计时，动作与背景的帧同步问题尚未全面解决。
- 动作幅度不是自动防穿模；特殊动作可能仍需手动调整 IK、源骨架、骨骼映射、位移和高度。
- 不包含 MMD 相机、灯光、模型导入、多角色同步和 MMD 物理；没有对应游戏通道的材质表情无法复现。音乐变速会改变音高。

反馈问题请到 [本分支 Issues](https://github.com/OedoSoldier/Endfield-Poser/issues)，附版本、复现步骤和必要日志片段，先检查日志中的个人路径。使用前请阅读 [README 中的免责声明](../../README.md#免责声明)。
