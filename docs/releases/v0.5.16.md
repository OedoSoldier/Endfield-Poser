# 0.5.16 — 跟踪镜头、物理增强与表情改进（预发布）

本次包含 0.5.2 之后的功能与修正，单人和多人共用相关设置。

## 更新内容

- **固定跟踪镜头**：锁定当前角色，保持拍摄方向，固定距离和焦距，无需镜头文件。支持构图偏移、角度调整及保存参数。
- **不跟踪跳跃**：可选锁定镜头高度，只跟随水平位移，默认关闭。开启后也不跟随坡道和台阶的高度变化。
- **衣物惯性物理增强**：衣物、头发、尾巴等根据动作中的位移和转身产生摆动，补充上下起伏响应；修正开启服装碰撞增强后的惯性响应，可调强度和轻盈度。
- **第二骨骼物理增强**：内置随身体运动的次级摆动，可调方向响应、回弹与限位，无需另装 SBM。仅在 MMD 中生效，支持暂停、拖动和停止恢复。
- **组合表情绑定**：中文标签和搜索，一条表情可绑定多个目标、分别设置强度；支持按住预览单项或组合，松开恢复。
- **口型校准修正**：更新内置 37 份角色表情校准，改善嘴边异常亮块、露齿和组合口型，并调整男管理员嘴形。

## 功能入口

| 功能 | 位置 |
|---|---|
| 跟踪镜头、不跟踪跳跃 | 单人或多人 **镜头与音乐 → 固定跟踪镜头** |
| 惯性与第二骨骼增强 | 单人 **动作 → 衣物物理**；多人 **站位与适配** |
| 表情组合与预览 | **表情 → 手动绑定（高级）** |

固定跟踪在暂停、停止动作或隐藏面板后继续工作；关闭跟踪或切换角色时退出。表情预览需冻结角色或暂停单人播放；多人播放期间先停止，再逐个编辑。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击新版包内的 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选 **安装或更新**。
3. 启动游戏，按 **L** 打开面板，从上述入口使用新功能。

无需先卸载。向导自动备份旧文件，保留配置、姿态和个人校准。随包表情校准自动更新；用户自行修改过的同名校准会保留并提示。

附件只提供编译好的标准安装包，不含 XXMI 联动或独立 SBM。GitHub 自动列出的 **Source code** 是源码，安装请选择 **win64.zip**。
