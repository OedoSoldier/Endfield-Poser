# Endfield Poser 0.4.91

Windows x64 预发布版。[打开下载页](https://github.com/OedoSoldier/Endfield-Poser/releases/tag/v0.4.91)

## 本次更新

- **手臂扭转**：修正上臂、前臂到手腕的扭转分配，利用角色已有辅助骨改善转腕时的变形，保留骨长、肘部弯曲和手掌朝向。
- **拇指基准**：为内置骨架建立独立的拇指张开方向，修正 A／T 姿参考切换引入的额外扭转，各节仍独立响应动作。选择 PMX 时保留文件定义的拇指形状。

两项修正自动生效，单人和多人均适用，无需新增设置或重新校准。

44 组自动化测试通过；臂部与拇指修正、此前的表情和景深改进仍待完整实机复测，本版继续按预发布提供。

## 安装与更新

在 **Assets** 下载 **Endfield-Poser-v0.4.91-win64.zip**。`source.zip` 和 **Source code** 是源码，不能直接安装。

1. 完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击**新版包内的安全安装.bat**，选择直接包含 `Endfield.exe` 的游戏目录，再选 **安装或更新**。
3. 启动游戏，按 **L** 打开面板；需要光标时按住 **Alt**。

无需先卸载。向导自动备份，保留配置、姿态和自定义校准，并安装 37 份内置表情校准。衣物资源已内嵌 DLL。标准安装包不含 XXMI 联动；通过 EFMI 启动游戏仍可使用标准版。

**快捷键**：**Ctrl+F5 播放、Ctrl+F6 暂停、Ctrl+F7 停止、Ctrl+F8 重置动作**，隐藏面板后仍可使用。已有自定义按键保留。
