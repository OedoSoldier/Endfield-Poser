# 0.5.18 — 独立头发惯性强度（预发布）

## 更新内容

- 新增 **头发惯性强度**，独立调整头发对跳跃、移动和转身的响应，不影响衣物强度。
- 范围 **0–3**，默认 **1**；设为 **0** 关闭头发的额外受力，保留游戏原生物理。支持双击输入、复位和随适配预设保存。
- 单人、多人均可使用，也可与服装碰撞增强一起开启。单人、多人共用强度设置，各角色分别计算。

单人入口：**动作 → 衣物物理 → 衣物惯性物理增强**；多人入口：**站位与适配**。跳跃反应较弱时，可将头发强度调至 **1.5–2** 对比；保持 **冻结头发／衣物** 关闭。实际摆动仍受角色原生物理约束和受力上限影响。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击新版包内的 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选 **安装或更新**。
3. 启动游戏，按 **L** 打开面板，调整头发惯性强度。
