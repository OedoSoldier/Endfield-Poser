# 0.5.41 — 脸红映射、Blender 重连与播放菜单整理（预发布）

## 更新内容

- **游戏原生脸红**：自动映射 MMD 脸红表情，支持单人、多人及 Blender 联动。在 **MMD 播放器 → 表情 → 脸红样式** 按角色选择样式 0（默认）或样式 2，无需手动调整材质参数。
- **Blender 联动 0.2.8**：修复重开工程后连接失败，以及重新导入动作、镜头时已有修正层失效的问题，保留修正层、关键帧和启用状态。受旧版本影响的工程可点击 **重新启用已有修正层**。新场景默认 **30 FPS**，可手动设置 1–120 FPS；已有工程保留原帧率，修改帧率不会自动移动关键帧。
- **第一人称与限帧**：MMD 支持第一人称播放，多人可选择第 1–4 位队员。主面板新增 **游戏帧率**，可选不锁定、30 FPS 或 60 FPS；默认不锁定，关闭时恢复原设置，隐藏面板后仍生效。
- **单人／多人菜单整理**：动作、镜头与音乐、表情、物理、Blender 和高级设置按用途分组，常用播放功能优先，自动适配设置收进高级选项。
- **安装器在线更新**：自动获取最新标准安装包（含预发布版），默认 GitHub 优先，失败后尝试内置国内镜像；支持镜像优先和自定义 HTTPS 镜像。下载校验通过后安装，保留配置、姿态与个人校准，不会降级。
- **管理员衣物调整**：改进外套增强初始化与腿部碰撞；男管理员左右大腿使用对称、等粗的碰撞体，保留小腿补强，移除额外胸腰及男管理员骨盆补强。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击新版包内的 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选 **安装本地包**。后续可在同一向导选择 **在线安装 / 更新**。
3. 启动游戏，按 **L** 打开面板。无需先卸载，向导会备份旧文件并保留用户数据。

使用 Blender 联动的用户也需更新插件：保存工程并关闭 Blender，重开后在 **Blender 5.2 或以上版本 → 插件管理 → 从磁盘安装** 选择包内的 **Blender联动插件.zip**，启用 **Endfield Poser Bridge**。普通 MMD 播放无需 Blender。

附件只提供编译好的标准安装包，不含 XXMI 联动。GitHub 自动列出的 **Source code** 是源码，安装请选择 **win64.zip**。
