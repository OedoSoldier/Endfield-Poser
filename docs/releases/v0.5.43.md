# 0.5.43 — Blender 小队编辑（预发布）

## 更新内容

- **最多四人同时编辑**：按游戏小队顺序导入骨架，各自调整动作、缩放、表情及修正层，共用时间轴和镜头。
- **逐人导出与播放**：每位队员分别导出动作与表情，公共镜头单独导出。多人播放器可混用 VMD 与 Blender 动作，继续使用逐人动作校准和物理增强。
- **连接与恢复**：连接保留当前姿态，正在播放的动作暂时暂停；断开后恢复。小队变化、实例失效或连接超时会结束联动。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，完整解压到游戏目录之外的文件夹。
2. 双击 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选 **安装本地包**；也可通过安装向导的 **在线安装 / 更新** 获取新版。
3. 使用 Blender 时，保存工程，从 Blender 插件管理中安装包内的 **Blender联动插件.zip**，更新后重开 Blender。本次需同时更新至游戏端 **0.5.43** 和联动插件 **0.3.0**。

无需先卸载，安装器会备份旧文件并保留配置、姿态和个人校准。附件只提供编译好的标准安装包；请选择 **win64.zip**，不要下载 GitHub 自动列出的 **Source code**。

## 多人使用方法

1. 在游戏 **MMD 多人播放器 → 队员与动作** 勾选参与成员、分配动作；也可不加载动作，直接编辑当前姿态。
2. 在 Blender **N → Endfield** 选择 **小队（最多 4 人）** 并连接，点击 **导入动作／表情／镜头**。通过队员按钮切换编辑对象，回放时全队同步预览。
3. 逐人 **导出当前队员动作与表情**，公共镜头只导出一次。断开后，在游戏对应队员的 **选择动作** 中加载 `.epmotion`，在 **Blender** 页加载 `.epcamera`。

动作文件已包含站位和朝向，加载时会复位该队员的额外站位偏移。每份动作需用于对应角色；新导出的小队动作需使用 **0.5.43 或以上版本**播放。原有动作文件仍可读取，继续编辑请保存 `.blend` 工程。

53 组游戏端测试及 Blender 回归测试通过，已检查实际导出文件的读取与采样；四人游戏内同步及视觉效果仍待进一步实测，本版为预发布。
