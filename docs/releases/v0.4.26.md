## 更新内容

- **启动兼容性**：等待游戏运行时就绪后再初始化插件；加载、配置和日志路径不再依赖启动目录。已在本机验证直接启动进入角色场景，保留经鹰角启动器启动的方式。
- **EFMI / XXMI 面板**：避免 D3D11 加载被代理重定向，使用系统模块、WARP 覆盖层与非阻塞回读。本机已验证 EFMI 启动后的面板显示、隐藏和持续绘制；该模式可能增加 CPU 开销。
- **BBC 原生布料接入**：在原生布料求解前提交当前动作，播放时使用当前骨骼的同帧模拟；暂停继续模拟，停止恢复原调度。可为当前角色已启用的衣物、头发和尾巴设置完整模拟／混合权重，退出后恢复。
- **裙摆碰撞覆盖**：可选边碰撞，按原有大腿胶囊半径与实际骨长添加临时原生胶囊，覆盖大腿、膝盖和小腿。增加碰撞余量调整和实际登记状态；关闭、停止或换人时撤销临时组件。仍由游戏 BBC 求解，效果尚待逐角色验证。
- **脚底防穿地**：可选游戏地面探测、坡面修正或固定平面，提供鞋底厚度、修正强度和高度调整；默认关闭。
- **冻结默认值**：“冻结飘带／裙子／头发”默认关闭，冻结身体时附件继续模拟；需要静止时可手动开启。MMD 的“冻结头发／衣物”也默认关闭。

既有 VMD 身体／手指／眼神／口型／表情、追加表情轨道、可选 PMX 骨架参考、手动 IK 与映射、动作幅度、播放快捷键及音乐同步功能保留。完整说明见 [MMD 播放指南](../mmd-player.md)。

## 安装或更新

1. **正常退出游戏**，确认游戏进程已结束。
2. 完整解压 `Endfield-Poser-v0.4.26-win64.zip`，打开 `Endfield-Poser-v0.4.26` 文件夹；不要在压缩包中运行脚本。
3. 双击 **`安全安装.bat`**，选择能直接看到 `Endfield.exe` 和 `GameAssembly.dll` 的游戏根目录，例如 `D:\Games\Arknights Endfield`。不要选启动器、`plugin` 或 `plugins` 子目录。
4. 选择 **1：安装或更新**，等待成功提示。脚本备份需要替换的 DLL，保留配置、布局、校准、姿态及同名适配预设；更新无需先卸载。
5. 按原有方式启动游戏：鹰角启动器、EFMI，或直接运行 `Endfield.exe`。插件的直启修复不替代游戏自身的更新、登录或服务要求。
6. 进入可操作角色场景，按 **L** 打开面板。需要光标时按住 **Alt**；窗口无法拖动时取消 **锁定窗口**，或点击 **重排窗口**。

**从旧版更新请完整运行安装向导**，启动兼容性改动也涉及代理 DLL，不要只替换 `poser.dll`。安装脚本不会启动或结束游戏；已安装文件被其他工具修改时会拒绝覆盖，应先核对文件归属。

主要文件位置：

```text
游戏根目录/
  Endfield.exe
  GameAssembly.dll
  d3dcompiler_47.dll
  vulkan-1.dll
  plugin/
    poser.dll
    poser-install.json
    poser-backups/
    mmd/rig-presets/
```

`plugin` 是单数。保留解压包的目录结构，安装向导需要同包的 `tools/deploy.ps1`。

**卸载：** 退出游戏，运行同一个安装向导，选择原游戏目录和 **2：卸载**。移除 Poser，并按安装记录恢复本工具管理的代理；配置、姿态和备份保留。其他插件仍依赖共用代理时会保留代理。

## 播放与碰撞设置

打开 MMD 播放器，选择 VMD 并完成角色校准。音乐需手动选择；IK 由面板手动控制，不按动作文件名或说明文件自动设置。

| 默认快捷键 | 行为 |
|---|---|
| `L` | 显示／隐藏面板，隐藏后继续播放 |
| `P` | 冻结／解冻；MMD 占用时先退出播放 |
| `Ctrl+F5` | 播放／继续 |
| `Ctrl+F6` | 暂停，保持姿态 |
| `Ctrl+F7` | 停止并恢复 |
| `Ctrl+F8` | 回到首帧并暂停 |

已有快捷键配置优先，以面板显示为准。

检查裙摆效果时，保持 **BBC 原生同帧碰撞**、**裙摆碰撞增强**、**补齐腿部原生碰撞** 开启，**冻结头发／衣物** 关闭。碰撞余量默认 **0.015**，过大会撑起裙摆。面板的“已提交”与“原生登记”分别表示请求和实际采用的数量；接口或骨架不兼容时会跳过，不能把参数已提交当成视觉验证通过。

## 验证范围与限制

- 0.4.26 已通过 **19 组本机自动测试**，覆盖启动时序、覆盖层、动作采样、角色切换、BBC 调度、碰撞组件创建与恢复等。测试代码和详细实验记录仅本机保留，不包含在发布源码中；公开源码可独立构建。
- 已在本机验证的直启与 EFMI 面板修复来自本轮开发版本的游戏实测，不代表全部机器、角色或模组组合都已验证。
- **裙摆仍可能穿模**：0.4.24 实测到原生裙摆、尾巴在运动，但长裙仍穿模；本版新增腿部覆盖尚未完成游戏内视觉验收。布料固定节点、蒙皮、动画限位和快速运动仍可能限制避让。
- BBC 调度开关影响全场景原生布料，可能增加 CPU 开销；临时腿部碰撞仅面向当前角色的兼容裙摆组件。不会改写腿部动作来强行防穿模。
- 脚底修正不等于衣物与地面的碰撞，也不处理身体／墙壁避让。仍不包含 MMD 相机、灯光、模型导入、多角色同步和 MMD 物理；音乐变速会改变音高。
- 游戏更新后接口可能变化；不兼容功能会显示未就绪或跳过。反馈时请提供版本、角色、动作及复现步骤，并从日志中移除个人路径。
