# 0.5.0（预发布）

## 更新内容

- **动作校准**：新增独立面板，可调整四肢伸展、手脚落点、整体移动和关节幅度，无需动作原始模型的 PMX。面板内可播放、暂停、逐帧和拖动进度，边看边调。
- **关节 XYZ 偏移**：在动作上叠加固定旋转角度，三轴同一行显示。每对关节的 X、Y、Z 可分别选择左右同向或镜像联动，支持归零及预设保存。
- **多人独立校准**：小队第 1–4 位可分别设置动作参数，也可使用共用参数。支持复制共用设置、分别保存和载入预设；保存与读取窗口记住上次文件夹。
- **输入与界面**：滑条支持双击输入数值，修复输入焦点问题。界面以 1080p 为基准，4K 默认 1.5 倍，支持手动缩放；修正缩小窗口后宽度缓慢回弹的问题。
- **眼神跟踪**：修正播放中眼神偶尔跳回原状态的问题，改进小角度转动、平滑与侧后方回正。新增按角色保存的转动幅度、注视深度、平滑时间及眼球中心微调。

动作校准入口：单人 **动作 → 动作校准…**；多人 **站位与适配 → 动作校准…**。多人设置按小队位置保留，换队或调整顺序后请检查对应参数；需要跨次使用时保存并载入预设。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击新版包内的 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选 **安装或更新**。
3. 启动游戏，按 **L** 打开面板，按住 **Alt** 操作。双击滑条输入后，按 **Enter** 确认或 **Esc** 撤销。

无需先卸载。向导自动备份旧文件，保留配置、姿态与个人校准；已有动作校准预设仍可读取，新联动规则默认同向。

附件仅提供编译好的标准安装包，不含 XXMI 联动。GitHub 自动列出的 **Source code** 是源码；普通安装请选择上方 **win64.zip**。
