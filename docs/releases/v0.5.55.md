# 0.5.55 — 透明截图与 MMD 序列录制

## 更新内容

- **人物透明截图**：保留角色的游戏光照与反光，输出透明 PNG，支持跟随游戏抗锯齿或 FXAA 兼容模式。
- **单人／多人序列录制**：按 30／60 FPS 逐帧输出，支持 VMD 和 Blender 导出的动作、表情与镜头。
- **分层同时保存完整成片**：输出完整画面、背景与透明人物；可将小队成员分别保存，各层帧号一致。
- **加快保存**：后台并行编码与写盘，提供快速无损 PNG、JPEG 背景；条件允许时复用人物颜色采集，减少重复渲染。缓存满时等待，不丢帧。
- **录制状态修复**：改进动作与镜头步进同步、取消后的状态恢复和完整帧保存；分层录制可显示进度遮罩，避免屏幕反复闪烁。
- 去掉截图与录制面板及说明中的“实验”标注。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，完整解压到游戏目录之外的文件夹。
2. 双击 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，选择 **安装本地包**；也可在已有安装向导选择 **在线安装 / 更新**。
3. 启动游戏，按 **L** 打开面板。安装器会备份旧文件，保留配置、姿态和个人校准，无需先卸载。

附件仅提供编译好的标准安装包，请选择 **win64.zip**；GitHub 自动列出的 **Source code** 不能直接安装。Blender 联动插件仍为 **0.3.0**，已安装该版本无需重新安装。

## 使用方法

- **截图**：冻结角色、暂停动作并固定镜头，在主面板 **人物透明截图** 点击 **保存人物透明 PNG**，输出至 `plugin/screenshots/`。
- **录制**：在播放器加载动作与镜头，展开 **MMD 序列录制**，选择帧率及分层方式，再点击 **开始录制序列**。输出至 `plugin/recordings/`，每次录制单独建目录。
- **后期制作**：`full/` 为完整场景 PNG；分层时另有 `background/` 和人物层。各层从 `000000` 同号排列，`recording.json` 记录帧率和配乐偏移。停止时保留已经完整保存的帧。

30／60 FPS 指导出序列的帧率；分层需要多次渲染，不能保证实时录制速度。序列不含音轨，需后期加入音乐。透明层的半透明材质、泛光、景深及遮挡存在限制；需要原始场景效果请使用 `full/`。录制时避免切换场景或改变分辨率；进度遮罩适用于窗口／无边框模式。

构建与录制回归检查通过；新增并行保存的实际游戏提速仍需按机器和场景验证。
