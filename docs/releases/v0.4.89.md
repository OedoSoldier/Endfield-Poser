# Endfield Poser 0.4.89

Windows x64 预发布版。[打开下载页](https://github.com/OedoSoldier/Endfield-Poser/releases/tag/v0.4.89)

## 本次更新

- **表情校准**：撤回近期测试版中导致表情错乱的新基准，恢复原有校准方式。已有校准文件无需删除或重新制作。
- **播放归零**：单人动作没有表情轨道时也会接管归零；单人 T 姿预览和多人播放准备阶段使用零表情权重，停止后恢复播放前的表情设置。
- **镜头对焦**：改进 MMD 镜头播放时的景深焦点同步，停止后恢复原设置。
- **移除倒计时**：删除单人、多人倒计时选项和屏幕数字，完成必要的衣物准备后直接播放。

44 组自动化测试通过。表情回退与拍照模式景深仍待完整实机复测；衣物增强仍可能穿模，本版继续按预发布提供。

## 安装与更新

在 **Assets** 下载 **Endfield-Poser-v0.4.89-win64.zip**。`source.zip` 和 **Source code** 是源码，不能直接安装。

1. 完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击**新版包内的安全安装.bat**，选择直接包含 `Endfield.exe` 的游戏目录，再选 **安装或更新**。
3. 启动游戏，按 **L** 打开面板；需要光标时按住 **Alt**。

无需先卸载。向导自动备份，保留配置、姿态和自定义校准，并安装 37 份内置表情校准。衣物资源已内嵌 DLL。标准安装包不含 XXMI 联动；通过 EFMI 启动游戏仍可使用标准版。

**快捷键**：**Ctrl+F5 播放、Ctrl+F6 暂停、Ctrl+F7 停止、Ctrl+F8 重置动作**，隐藏面板后仍可使用。已有自定义按键保留。
