# 0.5.31 — Blender 编辑与衣物物理改进（预发布）

## 更新内容

- **Blender 联动**：用与游戏对应的主要骨骼编辑动作、中文表情和镜头，实时预览。连接保留当前姿态；动作和镜头均支持修正层、关键帧及平滑恢复。
- **分开保存动作和镜头**：动作与口型、表情保存为 `.epmotion`，镜头保存为 `.epcamera`。在 **MMD 播放器 → Blender 联动** 加载，继续使用音乐、动作校准和物理增强；可编辑的图层保存在 `.blend` 工程中。
- **编辑与同步修复**：修正骨骼选择、打帧报错、原动作关键帧显示、导入镜头朝向和撤销时断开连接；修复联动约两分钟后动作、镜头不再更新的问题。操作反馈保留在面板，默认不输出插件控制台日志。
- **本次关闭 Poser**：主面板一键停止播放与联动，恢复角色、衣物和镜头并关闭工具。文件与设置保留，重启游戏后重新加载。
- **衣物与饰品改进**：飘带、腰带和挂件按挂点响应，可分别调整强度和复位；补充缺失的小腿碰撞，调整男女管理员外套固定点和腰部碰撞范围，移除男管理员腰腿之间的额外碰撞体，改进赛希飘带连接处的稳定性及衣物恢复流程。
- **播放细节**：支持 VMD 模型显示／隐藏关键帧；保留已存在的角色常驻特效；组合闭眼表情按左右眼限位。多人音乐偏移范围扩大至 **±120 秒**。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击新版包内的 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选 **安装或更新**。
3. 启动游戏，按 **L** 打开面板。无需先卸载或重新校准，向导备份旧文件并保留配置、姿态与个人校准。

需要 Blender 编辑时，在 **Blender 5.2 或以上版本 → 插件管理 → 从磁盘安装** 选择包内的 **Blender联动插件.zip**，启用 **Endfield Poser Bridge**。3D 视图按 **N**，在 **Endfield** 页签连接角色。旧联动插件也需更新，保存工程后重开 Blender。普通 MMD 播放无需 Blender。

附件仅提供编译好的标准安装包，不含 XXMI 联动。GitHub 自动列出的 **Source code** 是源码，安装请选择 **win64.zip**。
