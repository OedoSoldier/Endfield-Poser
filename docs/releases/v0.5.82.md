# 0.5.82 — 新版游戏适配与祀的表情、衣物改进

相较上一发布版 **0.5.71**：

- **新版游戏兼容**：更新服装物理增强适配，修复开启增强后动作和镜头无法开始的问题。暂未适配的特殊层间碰撞保留原有物理，不阻断播放。
- **祀的衣物增强**：裙摆与左右袖子独立运动，补充双臂、胸腹和腿部碰撞，调整腰侧碰撞范围；改善袖子下垂、回弹和沿布边弯曲，可通过衣物惯性强度、轻盈度调节。
- **表情修正**：修正表情基准与混合，改善眉眼偏移、舌头扭曲和停止后的恢复，更新祀的专属表情校准。
- **动作骨骼适配**：已有源骨骼支持自动匹配及手动修改；对“骨骼存在，但未连接到角色输出”的可识别部位，新增“一键接入已有骨骼”。标签采用“中文（日文／原名）”，修正选项显示与实际映射不一致的问题。
- **性能优化**：减少衣物增强中重复的骨骼与蒙皮绑定检查，保留换人、停止和失效检测。

动作适配入口：导入 VMD 后点击 **查看并处理… → 一键接入已有骨骼**。存在歧义或专用控制的轨道仍需手动处理；完成后点击 **应用并保存适配预设**。

本版继续作为预发布版。衣物效果取决于角色、动作和皮肤；祀袖子的侧向弯曲调整仍需更多实机反馈。

## 安装与更新

1. 完全退出游戏，将上方 **win64.zip** 完整解压到游戏目录之外。
2. 运行 **安全安装.bat → 安装本地包**，选择包含 `Endfield.exe` 的目录；也可通过原安装向导选择 **在线安装 / 更新**。
3. 旧文件自动备份，配置、姿态和自定义校准保留。启动后按 **L** 打开面板。

Blender 联动仍为 **0.3.2**，已安装该版本无需重复更新。附件只提供编译好的标准安装包；GitHub 自动列出的 **Source code** 不能直接安装。
