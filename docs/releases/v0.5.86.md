# 0.5.86 — 祀的袖子物理调整与播放准备修复

相较上一发布版 **0.5.82**：

- **袖子结构调整**：祀的左右袖子由三列改为单列六段，静止基准竖直向下，减少横向牵制。
- **下垂调整**：取消持续回拉静止方向的力，柔软度由根部向末端递增；保留身体与腿部碰撞，并同步调整飘带碰撞跟随和停止恢复。
- **播放准备修复**：支持纯骨链衣物的结构校验，避免将没有三角面的有效骨链误判为构建失败、阻断播放。

本版继续作为预发布版。已通过自动化回归与离线蒙皮检查；新版袖子的实际弧线和碰撞效果仍需实机反馈。

## 安装与更新

1. 完全退出游戏，将上方 **win64.zip** 完整解压到游戏目录之外。
2. 运行 **安全安装.bat → 安装本地包**，选择包含 `Endfield.exe` 的目录；也可通过原安装向导选择 **在线安装 / 更新**。
3. 旧文件自动备份，配置、姿态和自定义校准保留。启动后按 **L** 打开面板，在播放器 **物理** 中开启服装碰撞增强。

Blender 联动仍为 **0.3.2**，已安装该版本无需重复更新。附件仅提供编译好的标准安装包；GitHub 自动列出的 **Source code** 不能直接安装。
