# Endfield Poser 0.4.35（Windows x64 预发布）

本版新增首次使用协议弹窗和 MMD 镜头播放，保留已有动作、表情、音乐同步及 BBC 原生物理。**新镜头接管和弹窗点击尚待游戏内验收，衣物仍可能穿模**，继续以预发布提供。

## 下载

在 [Release 页](https://github.com/OedoSoldier/Endfield-Poser/releases/tag/v0.4.35) 的 **Assets** 中选择：

| 文件 | 用途 |
|---|---|
| `Endfield-Poser-v0.4.35-win64.zip` | Windows x64 预编译安装包，含 DLL、安装向导、许可和使用说明，无需编译 |
| `Endfield-Poser-v0.4.35-source.zip` | 对应提交的公开源码、构建脚本和依赖 |
| `SHA256SUMS.txt` | 两个 ZIP 的 SHA-256 校验值 |

GitHub 自动提供的 **Source code** 是源码，不含 DLL。安装包不包含动作、模型、音乐、本机配置、协议确认记录、校准、姿态或示例适配预设。

## 相比 0.4.26 的更新

- **首次使用协议**：参考 EIEM 的四部分说明，首次加载显示可滚动弹窗。点击“我已阅读并同意”后保存本机确认记录；“暂不使用”关闭提示并保持插件操作停用，游戏继续运行。普通更新保留确认，主面板可重新查看。未确认时冻结、MMD、表情接管和外部控制不可用；保存失败会提示重试。
- **MMD 镜头**：可导入独立镜头 VMD，或读取动作文件内的镜头。与身体、表情、音乐共用时间轴，支持暂停、拖动、循环、倍速及纯镜头播放。
- **镜头原点与跟随**：默认将开始播放时角色的位置和朝向作为固定参考；手动跟随模式叠加角色位移，可单独关闭垂直跟随。VMD 没有标准的角色跟随标志，因此不会按文件名或说明自动猜测。
- **镜头适配**：调整左右／上下／前后偏移、单位比例、距离比例、整体朝向及视角偏移，适配不同身高。支持透视／正交、六通道 Bézier 插值和相邻帧切镜；停止后恢复原相机状态。参数目前仅在本次运行保留。
- **组件查询**：校验 Unity `GetComponent(Type)` 和 `GetComponents(Type)` 的参数及返回类型，避免误选整数、字符串等同名重载；接口不匹配时跳过。
- **预设与衣物功能整理**：源码和安装包不再附带 `presets` 示例；仍可保存、载入自己的适配预设，更新保留现有文件。保留 BBC 原生衣物／头发／尾巴模拟，不包含 GPU 局部衣物修正和自动控制点功能。

“冻结飘带／裙子／头发”仍默认关闭。既有 IK 手动开关、源骨架补全与映射、整体／分部位动作幅度、音乐同步和播放快捷键继续保留。完整操作见 [MMD 播放指南](../mmd-player.md)和[协议说明](../user-agreement.md)。

## 安装或更新

1. 正常退出游戏，确认 `Endfield.exe` 进程已结束。
2. 完整解压 `Endfield-Poser-v0.4.35-win64.zip`，进入 `Endfield-Poser-v0.4.35` 文件夹。不要在压缩包中运行脚本。
3. 双击 **安全安装.bat**，选择直接包含 `Endfield.exe` 和 `GameAssembly.dll` 的游戏根目录，例如 `D:\Games\Arknights Endfield`。不要选择启动器目录、`plugin` 或 `plugins`。
4. 选择 **1：安装或更新**，等待完成。安装脚本会备份需要替换的 DLL，保留配置、窗口布局、协议确认记录、校准、自定义适配预设和姿态。更新无需先卸载，也不要复制他人的配置。
5. 按原有方式经鹰角启动器、EFMI 或直接运行游戏启动；游戏自身更新和登录要求不变。首次弹出协议时阅读后选择是否同意，按住 **Alt** 可呼出光标。
6. 确认后进入角色场景，按 **L** 打开面板。动作入口是 **MMD 播放器 → 打开 VMD**；镜头入口是 **MMD 镜头 → 选择镜头 VMD**。

相机接口不兼容时面板会显示状态，身体动作仍可使用。首次使用身体动作需完成角色校准；纯镜头播放无需身体校准。

| 默认快捷键 | 操作 |
|---|---|
| `L` | 显示／隐藏面板，隐藏后继续播放 |
| `P` | 冻结／解冻；MMD 占用时先退出播放 |
| `Ctrl+F5` | 播放／继续 |
| `Ctrl+F6` | 暂停并保持姿态 |
| `Ctrl+F7` | 停止并恢复 |
| `Ctrl+F8` | 回到首帧并暂停 |

已有配置优先，以面板显示为准。卸载时退出游戏，运行同一向导并选择 **2：卸载**；保留用户数据和备份，按安装记录恢复本工具管理的代理 DLL，其他插件依赖的共用代理会保留。日志位于 `plugin/poser_log.txt`，备份位于 `plugin/poser-backups/`。

## 验证范围与限制

- 本机 **24 组自动测试**和 **62 项安装检查**通过，包括协议持久化与布局、VMD 镜头解析／采样、相机对象恢复、表情回调、角色切换及 BBC 调度。公开源码可独立构建；测试代码、素材与详细实验记录仅本机保留。
- **尚未完成新增镜头接管与首次弹窗的游戏内操作验收**。自动测试与素材解析通过不代表所有角色、游戏版本、镜头方向或模组组合均已验证。
- 直启及 EFMI 覆盖层修复保留；此前已在本机游戏验证其启动及面板显示。EFMI 模式使用 WARP 软件覆盖层，可能增加 CPU 开销。
- 衣物模拟依赖原有骨骼、蒙皮和 BBC 设置，骨骼不足的长裙仍可能穿模；本版不宣称解决所有角色衣物碰撞。BBC 同帧调度可能增加 CPU 开销。
- 不包含 MMD 灯光、模型导入、多角色同步或 MMD 物理模拟；音乐变速会改变音高。反馈时请提供版本和复现步骤，删除日志中的个人路径。

## 校验与源码

运行 `Get-FileHash .\Endfield-Poser-v0.4.35-win64.zip -Algorithm SHA256`，与 `SHA256SUMS.txt` 对照。包内 `BUILD-INFO.json` 记录对应源码提交及 DLL 哈希，`FILE-SHA256SUMS.txt` 记录包内文件哈希。

对应源码见本 Release 的源码 ZIP 或仓库 `v0.4.35` 标签，按 AGPL-3.0 分发，附完整许可与第三方声明。源码构建需 MSVC x64 和 Windows SDK，运行 `build.bat`。更多信息见 [README](../../README.md)与 [Issues](https://github.com/OedoSoldier/Endfield-Poser/issues)。
