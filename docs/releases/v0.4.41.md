## 相比 0.4.35 的更新

- **分区表情映射**：眉毛、眼部、嘴部、脸颊分别选择“游戏表情映射”或“通用模板映射”。游戏映射沿用 EIEM 的固定对应表；新默认值全部为游戏映射，模板按需手动启用。
- **整体与独立强度**：整体和四个区域均可调节 0–200%，最终倍率为整体强度 × 区域强度。播放或暂停时均可调整；“恢复默认分区”只重置映射方式，“复位全部强度”只将倍率恢复为 100%。
- **可选通用模板**：按角色中性脸骨骼尺寸生成 38 个模板，覆盖眉形、眨眼／笑眼、半睁眼、元音、嘴角、噘嘴、抿嘴及鼓腮等。ω 和三角嘴为骨骼近似；不包含材质、瞳孔、牙齿显隐等特效。
- **分区写入与恢复**：选择模板的区域不会接收游戏口型附带的该区域增量。使用同步快照传递表情，停止后恢复原状态；角色或中性基准变化后使旧快照失效并重新绑定。
- **配置保存**：游戏对应表与模板对应表分别保存，分区模式、区域强度和整体强度在下次启动恢复；保存采用临时文件替换。缺少模板所需骨骼时，已经就绪的游戏映射区域仍可使用。
- **协议第 2 版**：文档和弹窗统一补充鹰角官方创作限制、用户产物责任及免责范围，突出显示重要条款。旧确认记录不代替本版确认，安装包不替用户预先同意。

保留 MMD 动作、镜头、音乐同步、手动 IK 开关、骨架适配与 BBC 原生物理支持。“冻结飘带／裙子／头发”仍默认关闭，不包含实验性 GPU 衣物修正或自动控制点功能。

## 安装或更新

1. 正常退出游戏，确认 `Endfield.exe` 进程已结束。
2. 完整解压 `Endfield-Poser-v0.4.41-win64.zip`，进入 `Endfield-Poser-v0.4.41` 文件夹。不要在压缩包中运行脚本。
3. 双击 **安全安装.bat**，选择直接包含 `Endfield.exe` 和 `GameAssembly.dll` 的游戏根目录，例如 `D:\Games\Arknights Endfield`。不要选择启动器目录、`plugin` 或 `plugins`。
4. 选择 **1：安装或更新**。向导会备份需要替换的 DLL，并保留配置、布局、协议记录、校准、表情设置、适配预设和姿态；更新无需先卸载。
5. 按原有方式经鹰角启动器、EFMI 或直接运行游戏启动。阅读第 2 版协议，选择是否同意；按住 **Alt** 可呼出光标。“暂不使用”保持插件操作停用，游戏继续运行。
6. 同意后进入角色场景，按 **L** 打开面板。在 **MMD 播放器 → 表情模板与强度** 中选择各区域的映射和强度；动作与镜头操作见 [MMD 播放指南](../mmd-player.md)。

**升级注意**：已有版本 2 的分区配置会原样保留，升级不会覆盖手动选择的模板。要统一切回游戏映射，请点击 **恢复默认分区**。0.4.38 的旧全脸配置会迁移为全游戏分区，保留整体强度和模板对应表。确认记录仍保存在本机，协议未再修订的普通更新不会重复要求确认。

| 默认快捷键 | 操作 |
|---|---|
| `L` | 显示／隐藏面板，隐藏后继续播放 |
| `P` | 冻结／解冻；MMD 占用时先退出播放 |
| `Ctrl+F5` | 播放／继续 |
| `Ctrl+F6` | 暂停并保持姿态 |
| `Ctrl+F7` | 停止并恢复 |
| `Ctrl+F8` | 回到首帧并暂停 |

已有快捷键配置优先，以面板显示为准。卸载时退出游戏，运行同一向导并选择 **2：卸载**；保留用户数据和备份，按安装记录恢复本工具管理的代理 DLL，其他插件依赖的共用代理会保留。日志位于 `plugin/poser_log.txt`，备份位于 `plugin/poser-backups/`。

## 验证范围与限制

- 本版通过 **27 组本机自动测试**，覆盖分区配置、混合映射、强度、暂停／停止及角色隔离、协议升级与弹窗布局等。公开源码独立构建及最终 ZIP 的隔离安装、更新、卸载另行检查；测试代码、素材和详细实验记录仅本机保留。
- **通用模板尚未完成所有角色和动作的视觉验收**，部分眉眼或嘴部效果可能不理想，默认使用游戏映射。计算对照通过不等于已修复所有表情幅度问题；没有相应输入轨道的帧不会因调高强度产生表情。
- 游戏表情映射没有模板的完整嘴角、噘嘴及鼓腮集合；未匹配轨道会在导入报告中提示，不自动混用模板。缺少骨骼的模板区域可能不可用，模板强度受闭眼、嘴唇和位移上限约束。
- 衣物仍依赖原有骨骼、蒙皮和 BBC 设置，骨骼不足的长裙仍可能穿模。EFMI 的 WARP 覆盖层及 BBC 同帧调度可能增加 CPU 开销；未宣称适配所有游戏版本或模组组合。
- 不包含 MMD 灯光、模型导入、多角色同步或 MMD 物理模拟；音乐变速会改变音高。镜头方向、偏移及相机接管仍需按角色和场景检查。

对应源码见本 Release 的源码 ZIP 或仓库 `v0.4.41` 标签，按 AGPL-3.0 分发，附完整许可和第三方声明。源码构建需 MSVC x64 和 Windows SDK，运行 `build.bat`。更多信息见 [README](../../README.md)；问题反馈至[本分支 Issues](https://github.com/OedoSoldier/Endfield-Poser/issues)，提供版本、复现步骤和必要日志片段，并移除个人路径等信息。
