# 0.5.17 — 固定跟踪镜头平滑（预发布）

## 更新内容

- 固定跟踪镜头增加 **跟随平滑（秒）**：默认 0.15，数值越大越柔和，也会更滞后；设为 0 关闭，支持双击输入和保存。
- 单人、多人均可使用，兼容 **不跟踪跳跃**；拍摄方向和焦距保持固定。首次开启或大幅瞬移时直接对齐，避免镜头长距离追赶。
- README 补充 SBM 项目链接、骨骼适配来源及许可说明。

入口：**镜头与音乐 → 固定跟踪镜头 → 跟随平滑（秒）**。更新后无需重新校准。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击新版包内的 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选 **安装或更新**。
3. 启动游戏，按 **L** 打开面板，按需调整跟随平滑。

无需先卸载。向导自动备份旧文件，保留配置、姿态与个人校准。附件仅提供编译好的标准安装包，不含 XXMI 联动；GitHub 自动列出的 **Source code** 是源码，安装请选择 **win64.zip**。
