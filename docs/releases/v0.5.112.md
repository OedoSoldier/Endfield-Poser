# 0.5.112 — 明河适配与字体、配乐兼容改进

相较上一发布版 **0.5.108**：

- **新增明河适配**：加入专属表情与拇指校准，接入服装碰撞增强；安装包现含 38 份角色表情校准。
- **调整明河外套**：减少腰胯附近的固定点，按 PMX 参考缩小上段碰撞间距；保留上身挂点、原有蒙皮，以及独立的尾巴和短飘带。
- **中文字体回退**：支持插件目录内的自定义字体，并补充 Wine 环境的字体查找；字体缺失或损坏时继续尝试其他字体。
- **WAV 配乐兼容**：常见 PCM／浮点 WAV 可直接读取，减少对系统解码组件的依赖；其他音频仍沿用原有解码方式。

本版继续作为预发布版。明河外套的实际观感仍待实机反馈；字体和配乐兼容改进不代表已解决新版游戏在 Proton 下的启动问题。

## 安装与更新

1. 完全退出游戏，将上方 **win64.zip** 完整解压到游戏目录之外。
2. 运行 **安全安装.bat → 安装本地包**，选择包含 `Endfield.exe` 的目录；也可在原安装向导选择 **在线安装 / 更新**。
3. 安装器自动备份旧文件，保留配置、姿态和自定义校准。启动后按 **L** 打开面板。

Blender 联动仍为 **0.3.2**，已安装该版本无需重复更新。附件仅提供编译好的标准安装包；GitHub 自动列出的 **Source code** 不能直接安装。
