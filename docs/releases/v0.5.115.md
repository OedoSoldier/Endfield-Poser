# 0.5.115 — MMD 眼神与组合表情修正

相较上一预发布版 **0.5.114**：

- **转头不再接管眼球。** 动作只有头部关键帧时，不会把眼神拉回正中。有眼神关键帧时，播放器按左右眼分别跟随；手动方向和锁定摄像机仍可覆盖动作眼神。
- **追加眼神不再丢轨。** 单人和多人播放 VMD 或 Blender 导出的 `.epmotion` 时，都可以追加眼神 VMD。只追加左眼会保留右眼和身体动作；`LeftEye`、`Bip001_R_Eye` 等名称也能识别。
- **改进小刻等角色的眼部表情。** 叠加眨眼、笑眼时，眼线和睫毛随眼皮一起限位。需要双眼的游戏表情，仅在两侧都可用时生效，避免只做出半边表情；单眼眨眼不受影响。

**安装或更新：** 完全退出游戏，下载上方 **win64.zip**，解压到游戏目录之外，运行 **安全安装.bat → 安装本地包**。已有安装也可选择 **在线安装 / 更新**。无需重新校准角色或重装 Blender 联动插件。
