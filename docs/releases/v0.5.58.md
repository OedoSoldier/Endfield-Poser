# 0.5.58 — Blender 断线保留编辑与自动重连

Blender 联动插件更新至 **0.3.2**，修复重连时被游戏姿态覆盖、跳回游戏帧，导致修改看似失效的问题。

- 断连后保留动作、表情、镜头、修正层及未打帧调整，可以继续离线编辑、保存和导出。
- 返回原角色／原小队场景后自动重连，保留 Blender 当前帧、帧率和镜头设置，无需重新导入动作。
- 多人重连先核对全队；角色、顺序或身体骨架不匹配时提示处理，避免覆盖已有编辑。
- 支持停止自动重连；导出期间等待完成再恢复连接。中断的动作导入不会替换已有动作和修正层。

## 更新方法

1. 下载上方 **win64.zip**，完整解压到游戏目录之外的文件夹。
2. **本次修复需要更新 Blender 插件**：先保存 `.blend`，在 Blender 插件管理中选择 **从磁盘安装**，选择包内 **Blender联动插件.zip**，启用 **Endfield Poser Bridge**，随后重开 Blender。只更新游戏插件不会更新 Blender 插件。
3. 如需更新游戏插件，完全退出游戏后运行 **安全安装.bat → 安装本地包**，或通过原向导 **在线安装 / 更新**。配置、姿态和校准保留，旧文件自动备份。联动 0.3.2 兼容游戏端 0.5.56 及以上版本。
4. 打开原 `.blend`，连接对应角色或小队即可继续，无需再次导入 VMD。镜头修复工具仍在安装包根目录。

若游戏因无操作返回登录界面，仍需重新登录并进入角色场景。请用 **Ctrl+S** 保存工程；断连保留编辑不等于自动保存到磁盘。
