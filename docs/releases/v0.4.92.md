# Endfield Poser 0.4.92

## 本次更新

- 所有角色的手指归零恢复游戏原生基准，修正梨诺等角色拇指被额外撑开、零帧手型偏移的问题。
- 保留动作中的手指旋转；内置 A／T 姿与自选 PMX 参考均适用，单人、多人一致。
- 首次运行会备份并清除旧身体／手指校准，播放时重新自动校准，避免沿用旧手型。表情校准与姿态库保留，新生成的校准不会重复清除。
- 保留此前的手臂扭转、表情归零及镜头对焦修正。

更新后自动生效，无需重新校准。44 组自动化测试通过；本版继续作为预发布提供，实际画面效果仍待游戏内复测。

## 安装与更新

1. 完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击**新版包内的安全安装.bat**，选择直接包含 `Endfield.exe` 的游戏目录，再选 **安装或更新**。
3. 启动游戏，按 **L** 打开面板；需要光标时按住 **Alt**。

无需先卸载。向导会备份原文件，保留配置、姿态和自定义校准。包内附带 37 份表情校准，衣物资源已内嵌 DLL；不含 XXMI 联动。

**Ctrl+F5 播放、Ctrl+F6 暂停、Ctrl+F7 停止、Ctrl+F8 重置动作**，隐藏面板后仍可使用。已有自定义按键保留。
