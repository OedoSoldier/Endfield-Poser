# 0.5.57 — 独立镜头修复工具

安装包新增 **镜头修复工具 1.0.0**，用于处理旧 `.epcamera` 丢失硬切镜信息、转场时闪出中间画面的问题。

- 选择对应的原始 **VMD 镜头**和旧 **.epcamera**，分析并勾选需要补回的切镜点，另存修复文件。
- 保留已调整的镜头位置、角度、焦距、对焦与时间轴，以及文件中已有的切镜标记。
- 支持时间偏移、范围检查和不同采样帧率的切镜对齐；候选点和实际时间会显示在列表中。
- 不覆盖原文件或已有输出。无需启动游戏，也无需安装 Blender 或 Python。

## 使用与安装

1. 下载上方 **win64.zip**，完整解压到游戏目录之外的文件夹。
2. **只修复镜头**：直接运行解压目录中的 **镜头修复工具.exe**，选择两个文件，点击 **分析切镜点 → 另存修复镜头**。时间轴未平移时偏移保持 `0`；从原镜头第 10 秒开始导出的文件填 `-10`。
3. **更新游戏插件**：完全退出游戏，双击 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选择 **安装本地包**；也可通过原安装向导 **在线安装 / 更新**。配置、姿态和个人校准保留，旧文件自动备份。

修复工具位于解压后的安装包根目录，不会自动复制到游戏目录。修复文件可在游戏中加载，或导回 Blender 继续编辑。Blender 联动插件仍为 **0.3.1**，已安装该版本无需重新安装。

附件仅提供编译好的标准安装包，请选择 **win64.zip**；GitHub 自动列出的 **Source code** 不能直接安装。

## 注意

参考 VMD 须与旧镜头对应，时间轴不能变速。相邻帧关键帧会列为候选硬切；大量逐帧烘焙的镜头默认不勾选，请核对真正的转场。工具补回切镜标记，不修复已经烘焙进文件的错误姿态、曝光或景深闪烁。

构建、真实旧镜头修复、中文路径、时间偏移、帧率对齐及防覆盖测试通过。详见[镜头修复步骤](https://github.com/OedoSoldier/Endfield-Poser/blob/v0.5.57/docs/camera-repair.md)。
