# 0.5.2 Hotfix — 拇指角度修正（预发布）

## 修复内容

- 修正 MMD 播放时拇指张开过大、弯曲方向异常的问题，覆盖根部、中节和末节。
- 默认源骨架下，拇指归零手型与动作方向统一使用对应角色的 PMX 参考，覆盖内置 37 个角色，单人、多人均适用。
- 保留手动指定的源 PMX、T 姿和手部映射；缺少角色参考时继续使用回退方式。

升级后无需重新校准。**高级 → 角色校准 → 按角色 PMX 校准拇指（含归零）**默认开启；若此前手动关闭，请重新开启以使用角色参考。

## 安装与更新

1. 下载上方 **win64.zip**，完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击新版包内的 **安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选 **安装或更新**。
3. 启动游戏，按 **L** 打开面板，播放动作检查手型。

无需先卸载。向导自动备份旧文件，保留配置、姿态与个人校准。

附件仅提供编译好的标准安装包，不含 XXMI 联动。GitHub 自动列出的 **Source code** 是源码，普通安装请选择 **win64.zip**。
