## 弹窗与确认记录

- 首次加载或协议修订后自动显示弹窗。点击 **我已阅读并同意** 后才启用操作；按住 **Alt** 可呼出游戏光标。
- **暂不使用** 关闭提示；再次按面板快捷键（默认 **L**）可以重新打开。未确认时冻结、MMD 快捷键、表情接管和外部控制保持停用，HTTP 控制返回 `403 agreement_required`。
- 确认记录只在本机的 `plugin/poser_agreement.txt` 保存协议版本和确认状态，不含账号、设备标识、素材路径或其他个人信息，不上传。
