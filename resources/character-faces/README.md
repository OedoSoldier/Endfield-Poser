# 角色表情校准

这里保存随插件分发的角色表情校准，目前共 37 份，覆盖 35 个角色标识。文件不包含模型网格、贴图、动作或本机路径。

MMD 表情参考自[茶叶味香皂](https://space.bilibili.com/3546783156276148)制作的《明日方舟：终末地》MMD 模型。感谢其模型制作与分享；模型及游戏资产的权利归各自权利人所有，相关素材请遵守原作者的使用规则。

打包时自动收录本目录的 `*.face.json`；安装时复制到游戏目录的 `plugin/mmd/character-faces/`，由插件按当前角色选用。

更新会替换安装器管理且未经修改的校准文件；用户修改过的同名文件会保留并提示。需要恢复内置校准时，退出游戏，将该文件移出运行目录，再运行安装向导。其他自定义校准、表情强度设置和身体校准不受影响；卸载时也会保留。

维护校准时请修改本目录。`plugin/` 仅保存本机运行数据，仍不纳入 Git。模型参考及相关创作须遵守各自授权和[用户协议](../../docs/user-agreement.md)。
