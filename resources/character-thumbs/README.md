# 角色拇指参考

`builtin.h` 保存逐角色 PMX 拇指参考，构建时编入 DLL，安装和打包无需额外复制模型文件。只保存归一化的骨骼方向、比例与来源摘要，不包含网格、贴图或本机路径。

播放器默认使用这些参考校准拇指归零姿势；可在 **高级 → 角色校准** 关闭。角色缺失、骨架不兼容或指尖数据不足时使用原生回退。

维护数据时运行：

```powershell
python tools/compile_character_thumbs.py "<PMX 模型目录>"
```

编译工具优先按 `resources/character-faces` 中的模型摘要确认角色身份；无表情资源时，核对 PMX 内的模型标识与多类贴图命名。不同版本的参考一致时合并，有歧义时跳过。普通构建不需要 Python 或原始 PMX。
