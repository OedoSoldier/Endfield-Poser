# Blender 动作编辑

在 Blender 5.2 或以上版本中调整动作、中文表情和镜头，在游戏里预览效果。只创建与游戏对应的骨架，不导入角色外观。普通 MMD 播放仍无需 Blender。

## 安装与连接

1. 按[安装说明](../../../README.md#安装更新与卸载)启用游戏内插件，确认使用协议并进入角色场景。
2. 在 Blender 的插件管理中选择 **从磁盘安装**，选择安装包内的 **Blender联动插件.zip**，启用 **Endfield Poser Bridge**。从源码安装时可将 `endfield_poser_bridge` 文件夹压缩为 ZIP，或运行 `tools/blender/install.ps1 -BlenderExe "Blender 程序路径"` 自动安装。
3. 在 Blender 的 3D 视图按 **N**，打开 **Endfield** 页签。
4. 选择 **当前角色** 或 **小队（最多四人）**，点击连接。新工程读取游戏当前姿态；已有匹配工程保留 Blender 当前帧、动作、表情和镜头修改，无需重新导入。正在播放的 MMD 会暂停。结束时点击 **断开并恢复游戏**，原本播放中的 MMD 会继续播放。

操作结果和错误直接显示在 Endfield 面板，默认不输出控制台日志。游戏内点击 **本次关闭 Poser** 会结束联动；重启游戏后可重新连接原工程。

联动插件 **0.3.2** 请配合游戏端 **0.5.56 或以上版本**使用。旧 `.epmotion` 的角色重载误报已兼容，无需重新导出。

### 游戏掉线后继续编辑

连接失效后，动作、修正层、表情和镜头仍在 Blender 中，可继续编辑、打帧、保存或导出。游戏重新进入原角色场景后会自动重连，并从 Blender 当前帧恢复同步；小队须保持原成员与顺序。角色或身体骨架不匹配时停止自动重连，提示切回原角色，不替换编辑骨架。

无需再次点击“导入动作／表情／镜头”。可点击 **停止自动重连** 留在离线模式，之后手动连接。请用 **Ctrl+S** 保存 `.blend`；断连保留的是当前工程内容，不能代替磁盘保存。若游戏因长时间无操作退回登录界面，仍需在游戏中重新登录。

## 导入与编辑

1. 在连接前点击 **选择 VMD 动作**，或先在游戏里打开动作。独立镜头文件勾选“作为镜头文件”。
2. 连接后选择开始帧、结束帧，点击 **导入动作／表情／镜头**。Blender 第 1 帧对应动作开始。新建联动工程默认 **30 FPS**，**场景帧率** 可设为 1–120 FPS；导入、实时预览和导出使用同一帧率，重连已有工程时保留它原来的帧率。
3. 拖动时间轴或按空格播放，勾选 **实时同步到游戏** 查看效果。
4. 骨骼在 Pose 模式中用 **R** 旋转；**G** 移动会改变关节位置，通常用于根节点或小幅修正。手指也可以直接选择。
5. **MMD 表情**面板按中文名称调节，右侧钥匙按钮打关键帧。镜头点击 **编辑镜头** 后，用 **G / R** 移动旋转，也可调整焦距和对焦距离；点 **镜头打关键帧** 保存当前构图。

骨架使用游戏实际名称、层级与关节位置。视图只显示躯干、四肢和手指；取消 **显示手指** 可进一步简化。衣物、头发和辅助骨不参与手动选择，原动作中的辅助骨轨道仍会同步。旧工程重新打开或连接后会自动整理显示。

新工程默认以 30 FPS 导入，也可在导入前改为 60 FPS 等帧率；“基数”通常保持 1。修改帧率不会移动已有关键帧，因此会改变播放时长。已有修正时应保持原工程帧率，除非也准备重新调整关键帧时间。

打关键帧前先点 **编辑骨骼**，选中需要的关节，再点 **给选中关节打关键帧**；只记录当前选中的可见关节。

## 小队编辑

需要游戏端 **0.5.43** 与联动插件 **0.3.0** 或以上版本。

1. 在游戏 **MMD 多人播放器 → 队员与动作** 按第 1–4 位分配动作，勾选参与成员；也可不加载动作，直接编辑当前姿态。
2. 在 Blender 选择 **小队（最多四人）** 后连接，再点击 **导入动作／表情／镜头**。队员同处一个场景，共用时间轴和镜头，以连接时的操控角色位置为共同原点。
3. 点击队员按钮切换编辑对象。每人独立保存动作修正层、缩放和表情关键帧；回放、拖动时间轴时，所有参与成员一起预览。
4. 分别选择每位队员，**导出当前队员动作与表情**；公共镜头只需导出一次。断开联动后，在游戏多人面板的对应位置 **选择动作** 加载 `.epmotion`，在 **Blender** 页加载 `.epcamera`。

导出的动作包含队员站位和朝向，载入时会复位该位置的站位偏移，避免叠加。每份文件只适用于对应角色；不能将一人的编辑动作直接套给四个不同角色。保存 `.blend` 后重开，保持小队顺序再连接，可继续使用各自的修正层。

## 重新编辑已导出的文件

先断开游戏连接，在 **从已导出文件继续编辑** 选择 **导入 .epmotion** 或 **导入 .epcamera**。

- `.epmotion` 还原骨架动作、缩放和口型表情，在新场景建立基础动作，原工程保留。新版导出文件附带参考骨架，可直接离线打开；旧文件需先打开对应角色的 `.blend`，或连接该角色取得骨架后断开。
- `.epcamera` 导入到当前编辑场景的新镜头，保留人物动作和旧镜头；也可在空场景中单独编辑镜头。转场、焦距与对焦距离会一并导入。
- 继续添加修正层或调整关键帧，再分别导出动作与镜头。文件中的最终结果已经包含之前的修正，不会自动再次叠加旧修正层。若要保留可单独调整的各层，请同时保存 `.blend` 工程。

新场景使用文件保存的帧率，旧文件默认 30 FPS；导入镜头到已有动作场景时沿用该场景帧率，按时间对应关键帧。导入过程中可按 **Esc** 取消。

## 用修正层处理穿模帧

1. 导入动作后，点击 **新建动作修正层**，原动作保留在底层。
2. 停在穿模帧，选中需要调整的关节，用 **G** 移动、**R** 旋转或 **S** 缩放，点击 **给选中关节打关键帧**，同时记录位置、旋转和缩放。
3. 到另一帧，点击 **恢复选中关节状态**，再点击 **给选中关节打关键帧**。关节偏移会自动平滑回到该帧的底层动作，无需设置起止帧或淡入淡出。
4. 可以继续添加其他修正层。面板分别显示 **当前编辑层** 和 **下层动作**；眼睛按钮开关某层，钥匙按钮在下方动作编辑器显示该层的关键帧；**查看全部层（NLA）** 展开完整层列表。

新建层后，动作编辑器显示新层的关键帧。查看原动作时点击其右侧钥匙按钮；点击 **返回顶层关键帧** 继续编辑顶层。各层仍一起参与播放。若在 NLA 中开启了下层独显，点击 **恢复全部层叠加** 才能预览当前修正。

也可以直接调整关节后打关键帧，插件会自动建立修正层。新关节修正会从动作开始的零偏移平滑过渡到第一个修正点；需要限定一段动作时，可先在前一帧记录恢复点。最后一个关键帧的偏移会持续保持，直到再记录恢复点。

勾选 **实时同步到游戏** 后，移动、旋转、缩放关节，修改关键帧或切换图层会立即预览；面板显示游戏已接收的帧数。导入、导出期间请等待进度完成后再编辑。

骨骼缩放需要游戏端 **0.5.42** 和联动插件 **0.2.9** 或以上版本，保存在 `.blend` 和导出的 `.epmotion` 中。恢复关节会恢复该帧下层动作的尺寸；断开联动或停止播放会恢复接管前的尺寸。支持正数缩放，不支持零缩放或负数镜像；建议优先使用等比缩放，非等比缩放叠加旋转时，游戏内的变形可能与 Blender 有差异。旧动作文件仍可读取，旧版插件未记录的缩放需要重新打帧。

关键帧、曲线和修正层都保存在 `.blend` 工程中，使用 **Ctrl+S** 保存。重启后打开该工程，连接相同游戏角色；重新导入只更新底层原动作和原镜头，保留修正层及其开关。旧版工程若显示修正层已关闭，点击 **重新启用已有修正层**，即可继续使用原关键帧。**Ctrl+Z** 撤销、**Ctrl+Shift+Z** 重做，连接继续保留并同步撤销／重做后的结果。

## 用修正层调整镜头

1. 点击 **编辑镜头 → 新建镜头修正层**，保留原镜头。
2. 在需要调整的帧修改位置、朝向、焦距或对焦距离，点击 **镜头打关键帧**。
3. 到另一帧点击 **恢复本帧下层镜头**，再打关键帧，构图会平滑回到下层镜头。

也可直接调整后打关键帧，自动建立镜头修正层。支持叠加多层；眼睛按钮同时开关该层的构图和镜头参数。骨骼与镜头共用时间轴，切换编辑对象后仍同步；请保持 **实时同步到游戏** 开启。

硬切转场会随镜头导入、修正和导出保留，游戏以更高帧率播放时也不会在两镜头间补出中间画面。在 Blender 中新增硬切，可将切换前的关键帧插值设为 **常量**。0.2.9 之前的工程若已丢失原 VMD 转场信息，请更新两端后重新导入原镜头（修正层保留），再导出 `.epcamera`。

只有旧 `.epcamera` 时，也可运行安装包内的 **镜头修复工具.exe**，提供对应的原始 VMD，核对并补回切镜点后另存。修复文件可直接播放或导入 Blender 继续编辑。

## 导出后在游戏播放

- **导出动作与表情**：保存为 `.epmotion`，包含角色骨骼、整体位移、口型及其他表情。
- **导出镜头**：保存为 `.epcamera`，只包含镜头位置、朝向、焦距与对焦点。

两者分别导出时间轴的开始帧至结束帧；可按 Esc 取消。表情、修正层和全部编辑内容保存在 `.blend` 工程中。

断开联动，在游戏 **MMD 播放器 → Blender** 分别加载动作、镜头。共用播放器的播放、暂停、进度、速度、循环、音乐、表情映射、动作校准及物理增强，无需另开播放器。口型和表情使用动作文件中的轨道，仍可调整游戏端的表情映射与强度。显隐继续使用游戏里加载的 VMD 轨道。

骨架动作是 Blender 最终姿态的烘焙结果；游戏的动作校准会在此基础上继续调整。希望保持导出姿态时，先复位动作校准。镜头文件可以单独替换；骨架动作需使用导出时对应的角色和骨架。

## 注意事项

- 当前角色和小队模式互斥；连接前先结束另一模式的播放和 T 姿校准。实时编辑时使用 Blender 时间轴，导出后可在游戏继续使用动作校准、表情映射和物理增强。
- 换人、换队或队员实例失效会结束旧连接并恢复仍存活的原角色。自动重连仅接受匹配的原角色／小队；手动连接其他角色会新建骨架，旧工程保留。
- 关闭 Blender 或连接中断后，游戏会在约 8 秒内退出编辑并恢复。立即重连会等待旧连接释放；请先关闭另一个仍在同步的 Blender 实例。也可在游戏中点“断开 Blender 并恢复”。
- 隐藏插件面板不会停止同步。切换窗口时需让游戏继续在后台运行。
- `.epmotion` 是本插件的编辑动作格式，不是 VMD。原始 VMD 保持不变；重新编辑应打开保存的 `.blend`。动作需用于同一角色；衣物辅助骨的增减或列表顺序变化会自动重新对应，身体骨骼缺失或父级改变时会提示具体骨骼。
- 联动只连接本机 `127.0.0.1:18923`。请先在游戏内确认使用协议。
